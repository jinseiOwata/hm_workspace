## この記事でわかること

- AIを使ってプレゼン資料の「構成(アウトライン)」をゼロから作る手順
- 構成をもとに各スライドの本文・箇条書きをブラッシュアップする方法
- 発表時に読む「スピーカーノート」をAIに作らせるコツ
- そのままコピペして使えるプロンプトテンプレート
- AIにプレゼン資料を作らせるときに気をつけたいリスクと注意点

プレゼン資料づくりで一番時間がかかるのは、スライドのデザインよりも「何をどの順番で話すか」を決める構成作業と、本番で言葉につまらないようにする発表原稿の準備です。白紙の状態から章立てを考えたり、スライド1枚ごとに話す内容を一字一句書き起こしたりする作業は、慣れていても意外と時間を取られます。

この2つはChatGPTやGemini、Copilotといった対話型AIがかなり得意とする作業です。構成のたたき台や発表原稿の下書きを人に頼むと時間がかかりますが、AIであれば条件を伝えてから数十秒〜数分で一通りの案が返ってきます。もちろん出てきた内容をそのまま使うのではなく、自分の言葉や社内事情に合わせて手直しする前提ですが、「ゼロから書く」のと「たたき台を直す」のとでは作業の心理的ハードルがまったく違います。この記事では、AIを「構成作成」と「スピーカーノート作成」の専任アシスタントとして使い倒すための具体的な手順を紹介します。

## AIでプレゼン資料を作る基本の流れ

AIにプレゼン資料を作らせるときは、いきなり「スライドを作って」と頼むよりも、工程を3段階に分けたほうが精度が上がります。

1. **構成(アウトライン)を作る**:タイトル・目的・聞き手を伝え、章立てとスライドごとの要点を出してもらう
2. **各スライドの本文を整える**:アウトラインをもとに、箇条書きや見出しコピーを磨く
3. **スピーカーノートを作る**:各スライドで実際に話す原稿を、時間配分込みで作成してもらう

この順番が大事な理由は、構成が固まっていないままスピーカーノートを作ると、後で構成を直したときに原稿も全部書き直しになるからです。先に「骨格」を確定させ、そのあとに「肉付け」をする、という順番を守るだけでAIとのやり取りが格段にスムーズになります。

使うAIツールは、ChatGPTやGemini、Microsoft Copilotなどの対話型AIで十分です。すでにPowerPointやGoogleスライドに組み込まれているAI機能がある場合は、それを使うとスライド化の手間も省けますが、本記事では「どのツールでも使えるプロンプトの作り方」に絞って解説します。プロンプトの考え方さえ押さえておけば、ツールを乗り換えても同じやり方で応用できます。

なお、AIとのやり取りは一度で完璧な答えを求めず、対話形式で少しずつ精度を上げていくのがコツです。最初の出力に対して「もっと具体的に」「専門用語を減らして」のように追加指示を重ねていくことで、だんだん自分のイメージに近づいていきます。一度で満足のいく答えが出なくても、諦めずに条件を足したり、逆に不要な条件を削ったりしながら調整してみてください。

## STEP1: AIに構成(アウトライン)を作らせる

最初のステップは、プレゼン全体の設計図となる構成案を作ることです。ここで手を抜くと、あとから章立てを大きく変える羽目になるので、最初にできるだけ情報をAIに渡しておきましょう。

### 伝えるべき情報の5点セット

AIに構成を考えてもらうときは、次の5つを最低限伝えます。

1. **プレゼンの目的**(例:新サービスの提案、社内の進捗報告、研修資料)
2. **聞き手は誰か**(役職、業界知識の有無、人数)
3. **持ち時間**(発表時間とQ&Aの有無)
4. **スライドの想定枚数**
5. **すでに決まっている素材や数字**(あれば箇条書きで貼り付ける)

### プロンプト例:構成作成

```
あなたはプレゼン資料作成の専門コンサルタントです。
以下の条件で、プレゼンの構成(アウトライン)を作ってください。

【目的】新しい勤怠管理システムの導入提案
【聞き手】経営層3名(ITに詳しくない、コスト意識が高い)
【持ち時間】15分発表+5分質疑
【想定スライド枚数】10枚程度
【伝えたい要点】
- 現行システムの課題(入力ミスが多い、集計に時間がかかる)
- 新システム導入による削減効果(月間の集計作業時間を想定)
- 導入コストと回収見込み
- 導入スケジュール案

出力形式:
スライド番号・タイトル・そのスライドで伝える要点(箇条書き2〜3個)
を表形式で出してください。
最後に、全体の流れが論理的かどうかの自己チェックコメントも添えてください。
```

このプロンプトのポイントは、出力形式を「表形式」で指定していることです。構成案を文章でもらうと、あとで読み返して直すときに読みにくいので、最初から表や箇条書きで出してもらうと編集が楽になります。

### 出てきた構成案の直し方

AIが出した構成案は、そのまま使うのではなく、必ず次の3点を自分でチェックしてください。

- **話の順番が聞き手にとって自然か**(結論が最後すぎないか、前提知識の説明が抜けていないか)
- **自社・自分にしか言えない具体的な情報が入っているか**(AIは一般論に寄りがちなので、固有の事例や数字は自分で補う)
- **時間配分が現実的か**(1スライド1〜2分換算で、持ち時間に収まっているか)

修正したい点が見つかったら、「3枚目と4枚目を統合して、導入効果のスライドをもっと前に持ってきて」のように、具体的に指示を出して構成を練り直します。AIは「全体を作り直して」と言われるより、「どのスライドを」「どう変えるか」を具体的に指定されたほうが、意図に近い修正をしてくれます。漠然とした指示よりも、修正箇所をピンポイントで伝えることを意識してください。

### 複数パターンを比較してから決める

時間に余裕があれば、構成案を1パターンだけでなく2〜3パターン出してもらい、比較してから採用するのもおすすめです。「結論から話す構成」と「課題から話す構成」のように切り口を変えて出してもらうと、自分では思いつかなかった流れに気づくことがあります。

```
今の構成案とは別に、
「結論(提案内容)を最初に伝えるパターン」の構成案も
もう1つ作ってください。スライド枚数は同じ10枚程度でお願いします。
```

複数案を並べて比較すると、自分のプレゼンの目的に合った流れを選びやすくなります。

## STEP2: スライドの骨子をブラッシュアップする

構成が固まったら、各スライドの本文(見出しコピーや箇条書き)を整えていきます。ここでは「情報を詰め込みすぎない」ことが最大のポイントです。

### プロンプト例:スライド本文の整形

```
以下は、プレゼンスライドの構成案の一部です。
このスライドの「タイトル(見出しコピー)」と「本文の箇条書き(最大4行、各行20〜25文字程度)」を作ってください。

【スライド番号】3
【伝えたい要点】
現行システムは紙の勤怠表を手入力しているため、
月末の集計作業に時間がかかっており、入力ミスによる
再確認作業も発生している。

条件:
- 専門用語は使わず、経営層にも分かる言葉にする
- 数字やデータがあれば、箇条書きの先頭に置く
- 煽り表現や誇張した言い回しは使わない
```

箇条書きの行数や文字数を具体的に指定するのがコツです。指定しないとAIは文章量を多く出しがちなので、「1行20〜25文字、最大4行」のように上限を決めておくと、スライドに収まる読みやすい分量に調整してくれます。

### 見出しコピーだけ複数案出してもらう

スライドのタイトル(見出しコピー)は、1つだけ出してもらうより複数案を並べて比較するほうが、しっくりくる表現を選びやすくなります。

```
このスライドの見出しコピーを5パターン出してください。
・体言止めのもの
・数字を使ったもの
・問いかけ形式のもの
をそれぞれ含めてください。
```

5パターンほど並べて見比べると、「この言い回しのほうが聞き手に刺さりそう」といった判断がしやすくなります。気に入った案をそのまま使ってもいいですし、2つの案のいいとこ取りをして自分で手を加えても構いません。

### デザインまでAIに任せたい場合

文章構成が決まったあと、スライドのデザインまで自動生成したい場合は、AIでテキストを入力するとスライドのレイアウトまで作ってくれるプレゼン作成ツールも増えています。ただし、こうしたツールは料金プランや無料枠の範囲、生成できる枚数の上限などが変わりやすいため、使う前に必ず公式サイトで最新の料金・機能を確認してから導入するようにしてください。本記事では、ツールを問わず使える「文章部分」の作り方に絞って解説しています。

## STEP3: スピーカーノート(発表原稿)を作る

構成とスライド本文ができたら、いよいよ本番で話す内容=スピーカーノートをAIに作ってもらいます。スピーカーノートは「スライドに書いていない補足説明」や「間の取り方」まで含めて作ってもらうと、本番の安心感が大きく変わります。

### プロンプト例:スピーカーノート生成

```
以下のスライド内容をもとに、発表用のスピーカーノート(読み上げ原稿)を作ってください。

【スライドタイトル】現行システムの課題
【スライドの箇条書き】
・紙の勤怠表を手入力しているため集計に時間がかかる
・入力ミスによる再確認作業が月に複数回発生
・担当者の残業の一因になっている

条件:
- 話し言葉で、1スライドあたり40〜60秒で話せる分量にする
- 聞き手(経営層)が数字でイメージできるよう、
  「どれくらい時間がかかっているか」を具体的に触れる一文を入れる
- 冒頭に「ここでは〜についてお話しします」という一言を入れる
- 文末は「です」「ます」調で統一する
```

「1スライドあたり何秒で話せる分量か」を指定するのが重要です。目安として、スライド1枚あたり40〜60秒程度を指定しておくと、持ち時間からの逆算がしやすくなります。15分の発表なら10〜15枚程度のスライドに収まる計算です。

### 話し方のクセを反映させる

スピーカーノートは「自分の話し方」に近づけるほど本番で読みやすくなります。次のように指示を追加すると、より自然な原稿になります。

```
上記の原稿を、以下の条件でリライトしてください。
- 一文を短くし、句読点で区切りすぎない自然な話し言葉にする
- 「〜となっております」のような硬い敬語は「〜です」に言い換える
- 間を取りたい箇所には「(間)」と入れる
```

### 想定質問とその回答もセットで作る

発表そのものだけでなく、質疑応答の準備もAIに手伝ってもらうと安心です。

```
このプレゼン内容に対して、経営層から出そうな質問を5つ想定し、
それぞれに対する回答案を3〜4行でまとめてください。
特にコストと導入リスクに関する質問を重点的に考えてください。
```

想定問答まで作っておくと、本番で厳しい質問が来たときも落ち着いて対応しやすくなります。余裕があれば、出てきた回答案をさらに「もっと短く」「数字の根拠も一言添えて」のように追加で磨き込んでおくと、質疑応答の本番でも慌てずに済みます。

### 時間配分表も一緒に作ってもらう

発表全体の時間管理に不安がある人は、スライドごとの所要時間をまとめた時間配分表もAIに作ってもらうと便利です。

```
これまで作ったスピーカーノートをもとに、
スライド番号・想定所要時間・累計時間をまとめた
時間配分表を作ってください。
持ち時間15分に対して余裕があるか、オーバーしていないかも教えてください。
```

こうしておくと、リハーサル前に「どのスライドで時間がオーバーしそうか」のアタリをつけられます。

## すぐ使えるプロンプトテンプレート集

ここまで紹介したプロンプトのうち、特に使い回しやすいものを3つにまとめました。空欄部分を書き換えるだけで、そのまま使えます。

**① 構成作成テンプレート**

```
【目的】
【聞き手】
【持ち時間】
【想定スライド枚数】
【伝えたい要点】
上記の条件でプレゼンの構成案を、
スライド番号・タイトル・要点(箇条書き)の表形式で作ってください。
```

**② スピーカーノート作成テンプレート**

```
【スライドタイトル】
【スライドの箇条書き】
上記の内容をもとに、1スライド40〜60秒で話せる
発表用スピーカーノートを話し言葉で作ってください。
文末は「です」「ます」調で統一してください。
```

**③ トーン調整テンプレート**

```
上記の文章を、以下の聞き手に合わせてトーンを調整してください。
【聞き手の属性】(例:専門知識のない新入社員/海外拠点の同僚/経営層)
専門用語には簡単な補足を入れ、一文を短くしてください。
```

この3つを使い分けるだけで、構成作成からスピーカーノート、聞き手に合わせた言い換えまで一通りカバーできます。

## AI生成プレゼンを使うときの注意点とリスク

AIにプレゼン資料作りを手伝ってもらうのは便利ですが、そのまま鵜呑みにすると危険な落とし穴もあります。最後に必ず押さえておきたい注意点をまとめます。

- **数字や固有名詞はAI任せにしない**:AIが生成した市場規模や統計データなどの数字は、架空の値が混ざることがあります。社外に出す資料では、必ず一次情報(社内データや公的統計)で裏取りをしてから使ってください。
- **社外秘・個人情報を入力しない**:顧客名や未公開の売上数値、個人が特定できる情報をそのままプロンプトに貼り付けるのは避けましょう。社内の利用ガイドラインがある場合は必ず従い、必要であれば仮名や丸めた数字に置き換えてから入力するのが安全です。
- **著作権・引用元の確認**:AIに「他社事例を調べて入れて」と頼んだ場合、出典が不明確なことがあります。社外発表資料に使う場合は、出典を自分で確認し、必要な許諾や引用ルールを守ってください。
- **話し方のクセは最終的に自分で読んで調整する**:AIが作ったスピーカーノートは一度は必ず声に出して読み、自分の話すスピードや言い回しに合っているか確認しましょう。読み上げてみて不自然な箇所は遠慮なく書き換えて構いません。
- **本番前に時間を計る**:AIが「40〜60秒」と見積もっても、実際に読む速度には個人差があります。最低1回はスピーカーノートを声に出して読み、持ち時間に収まるか確認してから本番に臨んでください。

これらを守ったうえでAIを使えば、構成を考える時間やスピーカーノートの下書きにかかる時間をかなり圧縮できます。ただし「作業時間が必ず半分になる」といった断定はできません。資料の難易度や自分の慣れによって効果は変わるため、まずは小さめの社内プレゼンから試してみるのがおすすめです。

## まとめ

- プレゼン資料作りは「構成→スライド本文→スピーカーノート」の順でAIに頼むと手戻りが少ない
- 構成を頼むときは目的・聞き手・持ち時間・枚数・素材の5点セットを最初に伝える
- スピーカーノートは「1スライド何秒で話すか」を指定すると、持ち時間に収まる原稿になる
- デザインまで自動生成するツールもあるが、料金や機能は変わりやすいので導入前に公式サイトで確認する
- 数字の裏取り、社外秘情報の入力禁止、声に出しての時間確認は省略しないこと

AIは構成案や発表原稿の「たたき台」を作る作業をかなり肩代わりしてくれます。ただし、最終的に聞き手の前で話すのは自分自身です。AIが出したものを鵜呑みにせず、自分の言葉で話せるかを必ずチェックしてから本番に臨んでください。
