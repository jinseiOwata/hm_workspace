## この記事でわかること

- Googleスプレッドシートに組み込まれたAI機能(Gemini)でできることの全体像
- 自由記述アンケートや問い合わせ内容を自動でカテゴリ分けする手順とプロンプト例
- 表記ゆれ・重複データをAIにクリーニングさせる具体的なやり方
- Apps ScriptからGemini APIを呼び出して、定型作業を自動化する応用方法
- 業務データをAIに入力するときに気をつけたいリスクと対策

スプレッドシートに貯まった「名前の表記ゆれ」「自由記述の分類」「重複行」の整理は、手作業だと地味に時間がかかります。この記事では、Googleスプレッドシートに統合されたAI機能と、Apps Script経由でのAI活用の両方を使い、こうした整理作業をどこまで自動化できるかを、実際に真似できる手順でまとめました。

## スプレッドシート×AIでできることの全体像

Googleスプレッドシートには、画面右側のパネルから呼び出せるAIアシスタント機能が組み込まれており、表の作成・要約・関数の提案などをチャット形式で依頼できます。これに加えて、スプレッドシートの拡張機能であるApps Scriptから外部のGemini APIを呼び出すことで、次のような「定型作業の自動化」も実現できます。

- 自由記述の問い合わせやアンケート回答を、決まったカテゴリに自動振り分け
- 表記ゆれ(「(株)」と「株式会社」など)や重複行の検出・統一案の提示
- 長い説明文やレビューのセル単位での要約
- 条件に合う行を抽出してレポート用の下書き文章を生成
- 複雑な関数や正規表現の組み立てを、日本語で依頼して提案してもらう

ポイントは、「AIに全部丸投げする」のではなく、仕分けやクレンジングのような判断に時間がかかる部分だけをAIに任せ、最終チェックは人間が行う、という役割分担です。特にデータ整理は「正解が1つに決まらない」作業が多く、AIの提案をたたき台として使い、最終的な採否は人が判断するという運用のほうが、結果的にやり直しが少なく済みます。

本格的にAIを使い始める前に、次の2点を確認しておくと手戻りが減ります。

1. **利用できるアカウントか確認する**:スプレッドシート内のAIアシスタント機能は、Google Workspaceの対象プランに含まれる機能で、個人の無料Googleアカウントでは表示されない、または機能が限定される場合があります。会社・学校のアカウントで使う場合は、管理者がAI機能を有効化しているかも含めて、最新の対象プランをGoogle Workspace公式サイトで確認してください。
2. **データの形を整える**:AIに渡す列は「1セル=1情報」になるよう整理しておきます。たとえば問い合わせ内容と対応状況が1つのセルに混在していると、AIが誤分類しやすくなります。可能であれば、IDとなる列(行番号や管理番号)を用意しておくと、AIの出力結果を元データと突き合わせやすくなります。また、1行目に明確な見出し(列名)を入れておくと、AIが各列の意味を正しく解釈しやすくなります。

準備ができたら、まずは基本操作であるAIアシスタントの呼び出し方から始めます。

## 手順1:AIアシスタントに表の要約・整形を依頼する

1. スプレッドシートを開き、画面右側のサイドパネルからAIアシスタント(Gemini)のアイコンを選択します。
2. 要約・整形したい範囲をあらかじめ選択しておくと、AIがその範囲を対象に処理しやすくなります。
3. チャット欄に依頼内容を入力します。以下はそのまま使えるプロンプト例です。

```
A列からD列までの売上データを、商品カテゴリごとに
合計金額と件数を集計した新しい表を作ってください。
出力は別シートに「カテゴリ」「合計金額」「件数」の
3列で整理してください。
```

4. 生成された表や提案内容は、必ず元データと数値を見比べてから採用します。特に合計・件数などの集計値は、関数(SUMIFSなど)で検算することをおすすめします。

AIアシスタントは、関数そのものを組み立てる相談にも使えます。たとえば複数条件での検索や、複雑な文字列抽出をしたいときに、次のように依頼すると具体的な数式案を提案してくれます。

```
E列の「顧客ステータス」が「契約中」かつ、
F列の「最終連絡日」が90日以上前の行を抽出したいです。
この条件に合う行番号の一覧をG1セルに返す数式を提案してください。
数式の意味も簡単に説明してください。
```

提案された数式は、必ず小規模なサンプルデータで動作確認してから、実データの範囲に適用してください。AIは列番号や範囲の指定を誤ることがあるため、特に「絶対参照・相対参照」の指定ミスは起こりやすいポイントです。

このステップはあくまで「叩き台づくり」です。次からは、より時間のかかる分類・クレンジング作業の自動化に入ります。

## 手順2:自由記述データをAIで自動分類する

アンケートの自由記述欄や問い合わせフォームの本文は、人手でカテゴリ分けすると時間がかかる代表例です。AIアシスタントに依頼する場合、分類基準をできるだけ具体的に示すのがコツです。

```
B列に入っている顧客からの問い合わせ本文を読み、
次の4つのカテゴリのいずれか1つに分類してC列に出力してください。

カテゴリ:
1. 料金・請求に関する質問
2. 操作方法がわからない
3. 不具合・エラーの報告
4. その他の要望・意見

分類結果はカテゴリ名のみをC列に出力し、
該当する本文が複数のカテゴリにまたがる場合は
最も当てはまりが強いもの1つだけを選んでください。
```

件数が数百行を超える場合は、AIアシスタントのチャットで一度に処理しきれないことがあります。その場合は後述するApps Script連携で、行ごとにAPIを呼び出すバッチ処理に切り替えると安定します。

分類結果をそのまま使わず、サンプルで20〜30行ほど目視チェックし、誤分類の傾向(例:皮肉っぽい文章を誤解する、専門用語を知らない)を把握してから本番適用するのが安全です。誤分類が多いカテゴリが見つかった場合は、プロンプトの「カテゴリ」部分に具体例を1〜2件追加すると、精度が改善することがあります。たとえば「2. 操作方法がわからない」に「例:ログインできない、ボタンの場所がわからない、といった内容」と補足するイメージです。

## 手順3:表記ゆれ・重複データをAIでクリーニングする

顧客名簿や取引先リストにありがちな「株式会社」と「(株)」の混在、全角・半角の違いといった表記ゆれは、ルールベースの置換だけでは対応しきれないパターンが残ります。AIにゆらぎの候補を洗い出してもらい、統一ルールの提案を受けるという使い方が有効です。

```
A列に入っている会社名のリストを確認し、
同一の会社を指していると思われる表記ゆれの
組み合わせを一覧にしてください。

出力形式:
「表記1」「表記2」「統一案」の3列で、
判断の根拠となった理由も簡単に添えてください。
判断に自信が持てない組み合わせは
「要確認」として別にまとめてください。
```

重複行の検出についても同様に、完全一致ではなく「表記は違うが同一人物・同一企業と思われる行」をAIに洗い出させ、最終的な削除・統合はユーザーが承認する、という流れにすると安全です。重複削除は元に戻しにくい操作なので、AIの提案をそのまま自動実行するのではなく、必ず別シートに一覧を出してから人の目でダブルチェックしましょう。

作業前に元データのコピーを別シート(またはファイル)として保存しておくと、万が一の誤削除・誤統合があっても元に戻せます。特に重複統合は「本当は別の会社・別の人だった」というケースも起こり得るため、住所や電話番号など複数の列を照合してから判断するのが安全です。

## 手順4:Apps Script×Gemini APIで自動化マクロを作る(応用)

行数が多い、あるいは毎週・毎月繰り返す定型作業であれば、Apps Script(スプレッドシートの拡張機能からアクセスできるスクリプトエディタ)からGemini APIを呼び出すカスタム関数を作ると、ボタン1つで処理を回せるようになります。

1. スプレッドシートの「拡張機能」メニューから「Apps Script」を開きます。
2. Google AI StudioでAPIキーを発行し、スクリプトのプロパティ(スクリプト プロパティ)にキーを保存します。コード内に直接APIキーを書き込むのは避けてください。
3. 以下のようなコードを入力し、セル単位でAPIを呼び出す関数を作成します。

```javascript
function classifyWithGemini(inputText) {
  const apiKey = PropertiesService.getScriptProperties().getProperty('GEMINI_API_KEY');
  const model = 'gemini-1.5-flash'; // 利用可能なモデル名は公式ドキュメントで要確認
  const url = `https://generativelanguage.googleapis.com/v1beta/models/${model}:generateContent?key=${apiKey}`;

  const payload = {
    contents: [{
      parts: [{ text: `次の問い合わせ内容を「料金」「操作」「不具合」「その他」
のいずれかに分類し、分類名だけを返してください。\n\n本文: ${inputText}` }]
    }]
  };

  const options = {
    method: 'post',
    contentType: 'application/json',
    payload: JSON.stringify(payload),
    muteHttpExceptions: true
  };

  const response = UrlFetchApp.fetch(url, options);
  const json = JSON.parse(response.getContentText());
  return json.candidates[0].content.parts[0].text.trim();
}

function runClassification() {
  const sheet = SpreadsheetApp.getActiveSheet();
  const lastRow = sheet.getLastRow();
  for (let row = 2; row <= lastRow; row++) {
    const text = sheet.getRange(row, 2).getValue(); // B列:問い合わせ本文
    if (text && !sheet.getRange(row, 3).getValue()) {
      const category = classifyWithGemini(text);
      sheet.getRange(row, 3).setValue(category); // C列:分類結果
      Utilities.sleep(500); // API呼び出し間隔を空ける
    }
  }
}
```

4. `runClassification` を実行すると、C列が空欄の行だけを対象にAPIを呼び出し、分類結果を書き込みます。すでに分類済みの行をスキップする条件を入れておくと、再実行時に無駄なAPI呼び出しが発生しません。
5. モデル名やAPIのエンドポイント仕様は更新されることがあるため、実行前に必ずGoogle AI Studioや公式ドキュメントで最新の名称を確認してください。
6. APIの利用には呼び出し回数に応じた料金が発生する場合があります。本番運用に入る前に、少量データでテストし、想定件数での費用感を公式の料金ページで確認しておくと安心です。

この仕組みは、分類だけでなく「要約」「表記ゆれの統一案生成」など、プロンプト部分を書き換えるだけで応用できます。さらに、Apps Scriptの「トリガー」機能を使えば、「毎日午前9時に自動実行」「スプレッドシートが編集されたら自動実行」といったスケジュール設定も可能です。ただし、自動実行の頻度を上げるほどAPIの呼び出し回数も増えるため、まずは手動実行で動作と費用感を確認してから、必要に応じて自動化の範囲を広げていくのが安全です。

## 注意点:個人情報・機密データを入力するリスク

AIにスプレッドシートのデータを読み込ませる際は、次の点に注意してください。

- **個人情報・機密情報の取り扱い**:氏名・電話番号・住所、社外秘の契約条件などを含む行を、そのままAIアシスタントやAPIに渡すのは避けましょう。どうしても分類などに必要な場合は、列を分けて個人情報部分をマスキングしてから渡す、あるいは社内のセキュリティ・コンプライアンス部門が許可した範囲内で利用するなど、組織のルールに従ってください。
- **組織のAI利用ポリシーを確認する**:会社のGoogle Workspaceアカウントでは、入力したデータの扱い(学習への利用有無、保存期間など)がプランや管理者設定によって異なります。業務データを入力する前に、情報システム部門やIT担当者に確認するのが安全です。
- **AIの出力を鵜呑みにしない**:分類や集計、重複検出の結果には誤りが含まれる可能性があります。特に金額や件数など数値が関わる処理は、関数による検算や抜き取りチェックを必ず行いましょう。
- **APIキーの管理**:Apps ScriptでAPIキーを使う場合は、スクリプト内に直接書かず、スクリプトのプロパティなど安全な場所に保存し、他人と共有しないようにしてください。
- **共有設定の見直し**:AI連携用に作成したスプレッドシートやスクリプトを、必要以上に広い範囲で共有していないか定期的に見直しましょう。特に個人の無料アカウントで作成したファイルを安易に「リンクを知っている全員」に設定すると、意図しない第三者にデータが見られるリスクがあります。

## まとめ

Googleスプレッドシートに組み込まれたAI機能と、Apps Script経由のGemini API連携を組み合わせると、表の要約づくりから、自由記述の分類、表記ゆれ・重複のクレンジングまで、これまで手作業で時間がかかっていた整理作業の多くを下書きレベルまで自動化できます。ただし、分類基準を具体的に指示すること、出力結果を必ず人の目で検算・確認すること、個人情報や機密データの入力には組織のルールを確認することの3点は、どの作業でも共通して意識しておきたいポイントです。まずは手順1のAIアシスタントによる表の整形から試し、慣れてきたら手順4のApps Script連携で定型作業の自動化に進んでみてください。
