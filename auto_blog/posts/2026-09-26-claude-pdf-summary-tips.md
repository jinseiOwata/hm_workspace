長いPDFを渡して「あとはよろしく」と丸投げすると、Claudeは一見それらしい要約を返してくれます。しかし実際に業務で使ってみると、「重要な数字が抜けている」「図表の内容が説明文からの推測になっている」「途中の章だけ雑になっている」といったズレに気づくことが少なくありません。これは性能の問題というより、PDFの読み取り方法とプロンプトの作り方が仕様に合っていないことが原因であるケースがほとんどです。

この記事では、Claude(claude.ai)で議事録・報告書・契約書・調査レポートなどの長いPDFを要約するときに、精度と時短を両立させるための具体的なやり方をまとめます。

## この記事でわかること

- Claudeに長いPDFを読ませるときの「ページ数・仕様の壁」と、その手前で失敗しないための考え方
- そのままコピペで使える要約プロンプトのテンプレート(用途別に4パターン)
- 100ページを超える分厚い資料でも精度を落とさずに読ませる工夫
- 機密情報の入力や誤読み(ハルシネーション)を避けるための注意点

## Claudeで長いPDFを要約する前に知っておきたい仕様

Claudeの強みは、PDFをテキスト変換せずにそのままアップロードするだけで、文章はもちろん図表やグラフ、スキャン画像まで読み取って要約・質問応答してくれる点です。ただし「何ページまでキレイに読めるか」には明確な境目があります。

Anthropic公式のヘルプセンターによると、Claudeは100ページ以下のPDFでは文字だけでなく画像・グラフなどの視覚要素も解析しますが、101〜1000ページのPDFはテキストのみを処理し視覚要素は解析されません。また1000ページを超えるPDFはそもそもアップロードできません。つまり、

- **〜100ページ**:図表・グラフ・レイアウトまで理解した「フル解析」
- **101〜1000ページ**:文字情報中心の解析(図の内容は説明文からしか推測できない)
- **1000ページ超**:アップロード不可

という3段階のイメージです。手元の資料が「本文はしっかりしているが図表がカギになる資料」なら、100ページを目安に分割したほうが安全です。また大きな資料を扱う場合は、あらかじめ小さなセクションに分割しておくと制限内に収まりやすくなります。ページ番号を指示するときも、PDFビューアーに表示される実際のページ番号を使うこと(資料に印刷された章番号などではなく)が公式にも案内されています。

なお、無料プランでもPro・Maxプランでも、この解析ロジック自体は共通です。有料プランで変わるのは主に「1日にどれだけ質問できるか」という利用回数の上限であり、PDFの読み取り精度そのものが上がるわけではない点は覚えておくとよいでしょう。

もう一つ意識したいのが、Claudeが返す答えは「そのファイルに書かれている情報のみ」を根拠にしているとは限らないという点です。文章量が多いPDFほど、途中の章の重要度をAI側が判断して「要約に含めるかどうか」を取捨選択します。そのため、資料のどこが自分にとって重要かを事前にプロンプトで伝えておかないと、読み飛ばしてほしくない箇所が省略されてしまうことがあります。仕様の限界を知ったうえで、次章からのプロンプトの工夫でカバーしていきましょう。

## 基本の手順:PDFをアップロードして要約させる3ステップ

「難しい設定はいいから、とにかく早く試したい」という方のために、まずは最もシンプルな使い方から紹介します。所要時間は資料を用意してから1〜2分ほどです。

1. Claude.aiのチャット画面を開き、入力欄の「+」またはドラッグ&ドロップでPDFを添付する
2. 添付が完了したら、要約の「目的」と「アウトプット形式」を1つのメッセージにまとめて送る
3. 出てきた要約に対して「◯章だけもっと詳しく」「数値の根拠ページを教えて」など追い質問で深掘りする

なお、パスワードで保護されたPDFや、スキャンの解像度が極端に低い資料は、正しく読み取れないことがあります。うまく要約が返ってこない場合は、まずパスワードを解除する、可能であれば元データ(Wordやテキスト)を用意する、といった対処を試してみてください。

基本形のプロンプトはこちらです。

```
添付したPDFを要約してください。
【目的】上司に5分で説明できるように概要をつかみたい
【形式】
1. 3行サマリー
2. 章ごとの要点(箇条書き3点まで)
3. 意思決定に関わりそうな数字・リスクを別枠で抽出
【注意】資料に書かれていないことは推測せず「記載なし」と明記してください
```

ポイントは「目的」と「記載なし禁止(=捏造しない)」を必ず添えることです。目的を書かないと、Claudeは当たり障りのない一般的な要約を返しがちで、あなたの業務に刺さる情報が抜け落ちます。

例えば同じ資料でも「上司に説明するため」と「契約リスクを洗い出すため」では、拾うべき情報がまったく違います。「要約して」だけで終わらせず、誰が・何のために読むのかまで一文添えるだけで、出てくる要約の使いやすさは大きく変わります。慣れないうちは、最初のメッセージに目的・形式・注意点の3点セットを入れることを習慣にしてみてください。

## 要約精度を上げる4つのコツ

### コツ1:章立て・見出し構造を先に確認させる

いきなり要約させず、まず「目次と章構成を箇条書きで教えて」と聞くと、Claudeがその資料をどう構造化して認識しているかが分かります。ズレていればここで軌道修正できます。特に、目次ページがない資料や、見出しの階層がバラバラなPDFでは、この一手間によって「どの章がどれくらいのボリュームか」を事前に把握でき、後続の質問で章番号を指定しやすくなります。

### コツ2:アウトプットの型を先に固定する

「3行で」「表形式で」「経営会議用のスライド原稿として」など、フォーマットを先に指定すると出力のブレが減ります。書式を指定しないと、資料ごとに文体や粒度が変わり、後で読み比べにくくなります。毎回同じ形式で要約を蓄積していきたい場合は、プロンプトの型そのものをテキストファイルなどに保存しておき、コピー&ペーストで使い回すと、指示出しの手間がぐっと減ります。

### コツ3:抜け漏れチェックを別質問で行う

要約が返ってきたら、続けて次のように聞くと精度検証になります。

```
今の要約に含めなかった重要な数値・日付・固有名詞があれば、
見落としがないか資料全体を再確認して教えてください。
```

一度で完璧な要約を狙うより、要約→検証→補足の2ステップにしたほうが結果的に速く正確です。

### コツ4:数字や固有名詞は原文を引用させる

金額・件数・日付などは、Claudeに数字だけ出させるのではなく「該当箇所を原文のまま引用して」と付け加えましょう。要約文だけを信じると、桁の読み間違いや章のとりまとめミスに気づけません。

このひと手間を惜しむと、あとで「資料のどこにその数字が書いてあったか探し直す」という余計な時間がかかってしまいます。引用元を最初から要約とセットで出力させておけば、後工程での確認作業が一気に短縮できます。

## 目的別プロンプトテンプレート集

前章の「基本形」プロンプトをベースに、用途ごとにアレンジしたものが以下の4パターンです。まずはこのままコピーして使ってみて、資料の分野や社内フォーマットに合わせて言い回しを少しずつ調整していくのがおすすめです。

### ① 経営会議向けエグゼクティブサマリー

```
このPDFを、経営会議で3分で説明する想定のエグゼクティブサマリーにしてください。
・結論を最初の1文で
・背景・課題・提案・懸念点の順に各2〜3行
・数字は資料内の記載通りに引用し、資料にない推測は書かない
```

### ② 章立て要約(目次ベース)

```
資料の章構成に沿って、各章200字程度で要約してください。
出力形式:
第1章:要約
第2章:要約
…
最後に「章をまたいで矛盾している記述」があれば指摘してください。
```

### ③ 複数資料の比較要約(同じチャットに2つ以上添付)

```
添付した資料A・資料Bを比較し、
①共通して主張していること ②食い違っている数値や結論 ③どちらか一方にしかない情報
の3項目に分けて整理してください。
```

### ④ リスク・数値抽出型(契約書・報告書向け)

```
このPDFから、リスクになりうる記載(免責事項、期限、罰則、未確定事項など)を
すべて抜き出し、「該当箇所の引用」「なぜリスクか」の2列で表にしてください。
```

いずれのテンプレートも、末尾に「資料にない情報は補完しない」「わからない場合は不明と書く」の一文を添えると、もっともらしい創作を防ぐ効果があります。テンプレートはあくまで叩き台なので、自分の業務でよく聞くフレーズ(「稟議」「議事録」「KPI」など)に置き換えてカスタマイズしていくと、毎回の指示出しがどんどん楽になっていきます。

## 100ページを超える資料を扱うときの工夫

100ページを超えると図表の解析が外れてテキスト中心になるため、以下のような対処が有効です。特に決算資料や年次報告書のように図表が要点を占める資料では、テキスト中心の解析だけに頼ると肝心の数値やグラフの傾向を取りこぼしてしまうことがあるので注意しましょう。

- **章ごとに分割してアップロードする**:1つのPDFを丸ごと渡すより、章単位で分けて「この章を要約→次の章を要約」と積み上げたほうが精度が安定します
- **Projects機能でまとめて管理する**:関連資料を1つのプロジェクトに入れておけば、チャットを新しく始めても資料を読み込み直す手間が減ります
- **図表が重要なページだけ画像として別添えする**:101ページ以降は視覚要素が解析対象外になるため、重要な図表ページはスクリーンショットを撮って画像として追加すると読み取ってもらえます
- **章ごとの要約を一つのメッセージに貼り戻して「全体総括」を作らせる**:各章要約が終わったら、それらをまとめて再度Claudeに渡し「これらを踏まえた全体サマリー」を作らせると、分割によって失われがちな全体の一貫性を補えます

利用頻度が高く、こうした分割作業を毎日繰り返すような使い方をする場合は、上位プランの検討価値があります。Claude Proプランは月額20ドル(年払いなら月額17ドル)で、これは標準的な利用であれば十分な上限です。さらに大量に使う場合の選択肢としてMax 5xプランは月額100ドルで、標準のProアカウントの5倍の利用量が用意されています。ただしMax プランはProより機能が豊富になるわけではなく、あくまで利用回数の上限が増える「利用量重視」のプランです。PDF要約だけが目的なら、まずは無料プランかProプランで十分か試してから検討するのがおすすめです(価格は変更されることがあるため、契約前に必ず公式サイトの最新表示を確認してください)。

## 情報漏洩・誤読みリスクへの注意

便利な反面、次の点は必ず意識してください。

- **機密情報・個人情報の入力に注意する**:契約書や人事資料、顧客の個人情報が含まれるPDFをそのままアップロードする前に、社内の情報取り扱いルールやNDAの範囲を確認しましょう。マスキング(黒塗り)してから読み込ませる、社外秘資料は無料プランではなく社内承認済みの契約形態で使う、といった配慮が必要です
- **アップロードしたファイルの扱われ方を確認する**:個人利用と組織利用ではデータの扱いに関する規約が異なる場合があります。学習利用の有無やデータ保持期間など、気になる点は必ず公式のプライバシー関連ページで最新の内容を確認してから、機微な情報を含む資料を扱うかどうかを判断してください
- **要約を鵜呑みにしない**:Claudeは非常に流暢な文章を作るため、実際には資料に書かれていない内容が紛れ込んでいても気づきにくいことがあります。重要な意思決定に使う数字や条件は、必ず元のPDFの該当ページに戻って人の目で確認する運用を徹底してください
- **社外への提出物にはそのまま使わない**:要約結果を顧客向け資料や公式レポートに転用する場合は、社内チェックのフローを一段挟むようにしましょう。時短のためのAIが、確認不足によるミスでかえって時間を奪う結果にならないようにすることが大切です

要約はあくまで「読む時間を短縮するための下書き」であり、最終判断の材料にする前に一次情報への立ち返りを習慣にすることが、時短と正確性を両立させる一番のコツです。慣れてくると、この確認作業自体もどこを重点的に見ればよいかが分かってきて、トータルの作業時間はしっかり短縮できます。焦って全行程を自動化しようとせず、「AIに下読みさせて、人が最終確認する」という役割分担を最初に決めておくと、安心して使い続けられます。

## まとめ

Claudeで長いPDFを要約するときは、まず100ページ・1000ページというページ数の壁を把握し、資料の性質に応じて分割するかどうかを判断することが出発点になります。そのうえで「目的」「出力形式」「記載なしの明記」をセットにしたプロンプトを使えば、一般的な要約より業務に使える精度に近づきます。

今回紹介したエグゼクティブサマリー・章立て要約・比較要約・リスク抽出の4テンプレートを、まずは手元の資料1本で試してみてください。1回使ってみるだけでも、どこを直せば自分の業務にもっと合うかが見えてくるはずです。慣れてきたら章ごとの分割やProjects機能での資料管理も取り入れつつ、機密情報の扱いと最終確認だけは省略しないようにしましょう。長いPDFとの向き合い方が変わるだけで、資料読み込みにかかる時間は着実に短縮できます。
