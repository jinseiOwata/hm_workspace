「もっと詳しく」「そうじゃなくて」とAIチャットに何度も言い直している──そんな経験はありませんか。実はその多くは、AIの性能の問題ではなく、プロンプト(指示文)の組み立て方の問題です。本記事では、ChatGPT・Gemini・Claudeなど、どのAIチャットツールにも応用できる「プロンプトを上達させる5つの基本パターン」を、そのままコピーして使える例文付きで紹介します。今日の作業からすぐに試せる内容になっているので、ぜひ手元のAIチャットを開きながら読んでみてください。なお、以下で紹介するパターンはAIチャットツールの種類を問わず使える考え方です。ツールごとの細かい仕様は異なっても、「どう指示を組み立てるか」という基本は共通しているため、普段お使いのサービスにそのまま当てはめて試してみてください。

## この記事でわかること

- AIチャットの回答が思い通りにならない原因と、改善のための基本の考え方
- すぐ真似できる5つのプロンプトパターン(役割指定・条件指定・具体例提示・手順分解・対話での改善)
- それぞれのパターンをどんな作業に使うと効果的か
- コピーして使えるプロンプトテンプレート
- プロンプト作成時に気をつけたい情報リスクと社内ルールとの付き合い方

プロンプトは「魔法の呪文」ではなく、相手(AI)に仕事の背景・条件・期待する形を具体的に伝える「指示書」です。指示書が曖昧なら、人間の部下でも的外れな成果物を出してしまうのと同じ理屈です。逆に言えば、指示の出し方にはコツがあり、それを押さえるだけで回答の精度は大きく変わります。

例えば「メルマガの文章を書いて」とだけ頼んだ場合と、「誰に」「何の目的で」「どんなトーンで」書いてほしいかまで伝えた場合とでは、同じAIでも返ってくる文章の完成度がまったく違います。AIは質問の裏にある意図を読み取るのが得意な一方で、書かれていない情報までは推測に頼るしかありません。つまり、プロンプトが上達するというのは「AIに伝える情報の解像度を上げる」ことに他ならないのです。

プロンプトを組み立てるときの基本の流れは、次の5ステップで考えると整理しやすくなります。

1. **誰として答えてほしいか**を決める(役割指定)
2. **どんな条件・形式で出してほしいか**を先に伝える(条件指定)
3. **どんな仕上がりが正解か**の見本を見せる(具体例提示)
4. **どういう順番で考えてほしいか**を指定する(手順分解)
5. **出てきた回答をどう直してほしいか**を対話で伝える(対話での改善)

どれも特別な専門知識は不要で、普段のチャット画面にそのまま書き込める内容です。それぞれのパターンには「どんな作業に向いているか」という得意分野があるので、自分の業務に当てはめながら読み進めてみてください。

## パターン1:役割を与えて回答の質を底上げする

AIは質問者の意図を推測しながら答えを作ります。何の前提もなく質問すると、当たり障りのない一般論が返ってきがちです。そこで有効なのが「役割(ペルソナ)指定」です。「あなたは〇〇の専門家です」と伝えるだけで、使う語彙や視点、回答の深さが変わります。

```
あなたは中小企業の人事労務に詳しい社会保険労務士です。
初めて有給休暇の管理表を作る総務担当者に向けて、
エクセルで管理する際の注意点を3つ、
専門用語には簡単な補足をつけて説明してください。
```

ポイントは「誰に向けて」「どんな専門性で」答えてほしいかをセットで伝えることです。役割だけ指定して読み手の情報がないと、説明の難易度がちぐはぐになりやすいので注意しましょう。

役割指定が特に効果を発揮するのは、次のような場面です。

- 専門的な内容を初心者向けにかみ砕いて説明してほしいとき
- 特定の立場(経営者・現場担当者・お客様など)からの視点でコメントがほしいとき
- 文章の硬さ・柔らかさといったトーンを調整したいとき

逆に、単純な事実確認や計算のような作業では役割指定の効果は限定的です。「この作業に専門性や視点の違いが関係するか」を基準に、使うかどうかを判断するとよいでしょう。

実際にやってみると違いがわかりやすいので、同じ質問を役割指定あり・なしの両方で試してみるのもおすすめです。例えば「有給休暇の繰り越しについて教えて」とだけ聞いた場合は一般的な説明に留まりがちですが、「社会保険労務士として、総務初心者にもわかるように」と条件を加えるだけで、説明の切り口や丁寧さが変わってきます。この違いを一度体感しておくと、他の作業でも役割指定を使うタイミングが感覚的につかめるようになります。

## パターン2:出力形式と条件を先に指定する

「いい感じにまとめて」という指示が伝わらないのは、人間同士でも同じです。文字数、形式(箇条書き・表・見出し付き文章など)、含めてほしい要素、除外してほしい要素を先に指定すると、手直しの回数が大きく減ります。

```
以下の会議メモを議事録の形式に整理してください。

【条件】
・見出しは「決定事項」「保留事項」「次回までのタスク(担当者名付き)」の3つ
・各項目は箇条書きで1項目1行
・文字数は400字以内
・雑談や脱線した話題は含めない

【会議メモ】
(ここに貼り付け)
```

このように条件を箇条書きで先に渡す「条件指定」は、議事録作成・メール文面・SNS投稿文など、フォーマットが決まっている作業と特に相性が良いパターンです。

条件を指定するときは、以下の3種類を意識して書き分けると漏れが減ります。

1. **形式の条件**(見出しの有無、箇条書きか文章か、表にするかなど)
2. **量の条件**(文字数、項目数、行数の上限・下限)
3. **内容の条件**(含めるべき要素、含めてはいけない要素、使ってほしくない言葉)

この3種類を毎回すべて書く必要はありませんが、「思っていたのと違う形で返ってきた」と感じたときは、どの条件が抜けていたのかを振り返ると、次のプロンプト作成に活かせます。

さらに、条件が多く複雑になりそうなときは、いきなり本文を書かせるのではなく「今から出す条件を踏まえて、まず構成案(見出しだけ)を提示してください」と一段階挟む方法も有効です。構成の段階で方向性を確認してから本文を作らせることで、大きな書き直しを避けやすくなります。

## パターン3:具体例を見せて仕上がりを揃える(Few-shot)

言葉で条件を説明するより、「こういう感じに仕上げてほしい」という実例を1〜2個見せたほうが早く正確に伝わることがあります。これは「Few-shotプロンプティング」と呼ばれる手法で、文体やトーン、粒度を揃えたいときに特に効果を発揮します。

```
以下の【例】のようなトーンと長さで、
新商品のお知らせ文を3本作成してください。

【例】
「残暑お見舞い申し上げます。〇〇店では秋の新作スイーツを
数量限定で販売中です。甘さ控えめで、コーヒーとの相性も抜群。
ぜひ店頭でお試しください。」

【新商品情報】
・商品名:
・特徴:
・販売期間:
```

例文は1つよりも2〜3つ見せたほうが、AIが「共通のパターン」を掴みやすくなります。既存の社内文書やお気に入りの過去の投稿文をサンプルとして貼り付けるのも手軽な方法です。

また、具体例を見せるときは「良い例」だけでなく「こうはしてほしくない例」をあわせて示すのも効果的です。「〇〇のような硬すぎる表現は避けてください」と避けたいパターンを具体的に見せることで、AIが条件を文章だけで理解するよりも誤解が減ります。

手元に適切なサンプルがない場合は、過去に自分や同僚が書いた文章の中から、評判が良かったものや読みやすいと感じたものを探してみてください。社外に出せる内容であれば、競合他社の公開文書やWeb上の記事の構成を参考にする(文章そのものをコピーするのではなく、構成や書き方の特徴を伝える)のも一つの方法です。

## パターン4:手順を分解させて思考の精度を上げる

複雑な依頼ほど、いきなり結論だけを求めると精度が落ちやすくなります。そこで「まず〇〇を整理して、次に△△を検討して、最後に結論を出して」というように、考える順番そのものを指示するのが4つ目のパターンです。

```
新しい業務ツール導入の是非を検討したいです。
次の手順で考えて回答してください。

1. 導入によるメリットを3つ挙げる
2. 導入によるデメリット・リスクを3つ挙げる
3. 1と2を踏まえて、導入すべきかどうかの結論と理由を述べる

【検討対象のツール概要】
(ここにツールの説明を貼り付け)
```

手順を分けることで、AIが途中の検討を飛ばして結論に飛びつくのを防げます。計算を伴う作業や、複数の条件を比較する相談ごとでは特に有効です。

さらに精度を高めたい場合は、各ステップの後に「ここまでの内容を一度要約してから次に進んでください」と指示を加える方法もあります。長い相談を一度に投げるのではなく、区切りながら進めることで、AIも人間も内容を把握しやすくなります。

この手順分解は、資料のたたき台作成やアイデア出しのように「正解が一つに決まらない相談」でも役立ちます。いきなり「良いアイデアを10個ください」と頼むよりも、「まず前提条件を整理する→条件に沿ったアイデアの方向性を3つ挙げる→それぞれの方向性でアイデアを2〜3個ずつ出す」というように段階を踏ませたほうが、的外れな提案が減り、後から選びやすい形でアイデアが並びます。

## パターン5:対話で改善を繰り返す(フィードバックループ)

一度で完璧な回答を得ようとせず、やり取りを重ねて精度を上げていくのも立派なプロンプトスキルです。最初の回答に対して「どこが」「どう」違うのかを具体的に伝え返すことで、AIは次の回答で修正点を反映してくれます。

```
先ほどの提案、方向性は良いのですが2点修正してください。

1. 専門用語(例:「KPI」「コンバージョン」)を
   使わず、社内の新人でも分かる言葉に言い換える
2. 全体を半分程度の文字数に短縮する
```

「もっと良くして」ではなく、「何を」「どう」直してほしいかを具体的に書くのがコツです。修正の指示を出すときは、以下のような観点で違いを言語化すると伝わりやすくなります。

- **長さ**:短くしてほしいのか、もっと詳しく書いてほしいのか
- **トーン**:硬すぎる・柔らかすぎる、専門的すぎる・くだけすぎている
- **構成**:結論を先に出してほしいのか、背景から説明してほしいのか
- **抜け漏れ**:触れてほしかったのに抜けていた観点は何か

1〜5のパターンを一度に全部盛り込む必要はありません。まずは役割指定と条件指定の2つだけでも意識すると、普段のやり取りの精度が目に見えて変わってくるはずです。慣れてきたら、具体例の提示や手順分解を組み合わせて、依頼内容の複雑さに応じてパターンを使い分けてみてください。

## 使うときの注意点(個人情報・機密情報のリスク)

プロンプトが上達してくると、つい業務データをそのまま貼り付けたくなりますが、以下の点には注意してください。

- 顧客の氏名・連絡先・契約内容などの個人情報は、仮名や「A社」「担当者X」のような記号に置き換えてから入力する
- 社外秘の数値・取引先名・未公開の企画内容などは、会社のAI利用ガイドラインを確認してから使う
- 入力したデータがAIサービス側の学習に利用されるかどうかは、利用するプランやサービスの設定によって異なるため、心配な場合は設定画面で学習利用のオン・オフを確認する
- AIの回答は誤り(ハルシネーション)を含むことがあるため、数値や固有名詞、法令・制度に関わる内容は必ず一次情報で裏取りする
- 著作権のある文章や画像をそのまま模倣させたり、他者の創作物を無断で加工・再配布したりしないよう注意する

特に無料プランや個人契約のプランでは、入力内容の扱いに関する設定が有料の法人向けプランと異なる場合があります。業務で使う前に、自分が使っているサービスの最新の利用規約・プライバシー設定を確認する習慣をつけておくと安心です。

また、勤務先によっては生成AIの利用自体に社内ルールが設けられていることもあります。「どのツールなら使ってよいか」「どんな情報は入力禁止か」といったルールが整備されている場合は、個人の判断でプロンプトを工夫する前に、まず社内のガイドラインを確認しておきましょう。ルールが未整備の場合でも、少なくとも顧客情報や契約書の原文など、第三者に関わる情報をそのまま貼り付けるのは避けるのが無難です。

## まとめ

AIチャットのプロンプトを上達させるコツは、難しいテクニックを覚えることではなく、「役割」「条件」「具体例」「手順」「フィードバック」という5つの型を、必要に応じて組み合わせることです。

- 役割指定で回答の専門性・視点を調整する
- 条件指定でフォーマットの手直しを減らす
- 具体例(Few-shot)でトーンや粒度を揃える
- 手順分解で複雑な相談の精度を上げる
- 対話でのフィードバックで少しずつ理想の回答に近づける

まずは今使っているプロンプトに、条件指定か役割指定のどちらか1つを足してみてください。それだけでも、AIからの回答の「使える度」が変わってくるはずです。

5つのパターンは、一度に全部覚えようとせず、普段よく使う作業(メール作成、資料の要約、企画のたたき台づくりなど)に1つずつ試していくのがおすすめです。「今日はこの作業に役割指定を足してみよう」「次はフォーマットを先に指定してみよう」というように少しずつ試していくうちに、自分なりの「使いやすいプロンプトの型」が自然とできあがっていきます。そして業務データを入力する際は、個人情報・機密情報の取り扱いルールを必ず確認した上で活用しましょう。プロンプトの質とリスク管理の両方を意識することが、AIチャットを長く安心して使いこなすための近道です。
