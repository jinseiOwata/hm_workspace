- 家族の情報をAIに入力するときに気をつけたいリスク

毎日の「今日何作ろう」を考える時間は、積み重なると意外と大きな負担になります。献立を考え、冷蔵庫の中身を確認し、買い物メモを書き、スーパーで売り場を行ったり来たり……。この一連の作業をAIに1週間分まとめて任せてしまえば、毎日考える代わりに「週に1回、条件を伝えて確認するだけ」の作業に変えられます。この記事では、ChatGPTやGeminiを使って、実際にその場で試せる手順とプロンプト例を、コピペですぐ使える形で紹介します。すでにAIチャットを使ったことがある方はもちろん、まだ使ったことがない方でも、この記事の手順通りに進めれば今日から試せる内容になっています。

## 献立づくりをAIに任せる基本的な考え方

AIに献立を考えてもらうコツは、一度にすべてを丸投げしないことです。人数・予算・好み・避けたい食材・冷蔵庫にある食材といった「条件」を先に整理してから渡すと、的はずれな提案が減ります。逆に「今週の献立考えて」とだけ送ると、家族構成も予算もわからないまま一般的な献立が返ってくるだけになり、結局自分で手直しする手間が増えてしまいます。

実際、ChatGPTで献立を相談する際は冷蔵庫にある食材を伝えるだけで、使い切りレシピを提案してもらえるうえ、人数や期間、予算を指定すれば、献立表と必要な食材リストまでまとめて出力できるという使い方ができます。つまり「条件を伝える→献立を出してもらう→買い物リストに変換してもらう→必要に応じて部分的に調整する」という4段階で進めるのが基本の流れです。この記事の手順1〜4は、そのままこの4段階に対応しています。

使うツールはChatGPTでもGeminiでも構いません。どちらも無料版でテキストのやり取りは十分にでき、1週間分の献立案を作る程度であれば無料枠でまかなえることがほとんどです。有料プランは、会話回数の上限を増やしたい場合や、他の作業(資料作成や画像生成など)もまとめて行いたい場合に検討すると良いでしょう。まずは無料版で一度試してみて、「もっと頻繁に使いたい」と感じたタイミングで有料プランを検討する、という順番がおすすめです。

## 使うAIツールと料金の目安(2026年10月時点)

無料で始めて、物足りなくなってから有料化を検討するのがおすすめです。2026年10月時点の料金目安は以下の通りです。

**ChatGPT**
ChatGPTの個人向けプランは、無料版・Go・Plus・Pro の4段階で、無料版は¥0、Goは月額¥1,400、Plusは月額¥3,000、Proは月額¥16,800からとなっています。献立作成だけが目的なら、無料版かGoで十分なことが多いです。

**Gemini**
Geminiも同様に無料版があり、個人向けは無料・AI Plus・AI Pro・AI Ultraの4段階です。有料プランはAI Plusが1,200円、AI Proが2,900円程度が目安で、Googleドキュメントやスプレッドシートと連携させたい場合はAI Proが候補になります。無料版と有料版の違いとして、無料版の文脈保持量は32Kトークンなのに対し、AI Pro以上では100万トークンまで扱えるという差もあります。1週間分の献立を何度もやり取りしながら作り込みたい人や、毎週同じ会話を継続して使い回したい人は、この文脈保持量の差を体感しやすいでしょう。

どちらを選ぶか迷ったら、普段使い慣れている方、あるいはすでにスマホに入っている方で構いません。献立と買い物リストの作成自体は、ChatGPTとGeminiのどちらでも同じ考え方のプロンプトで対応できます。普段からGmailやGoogleカレンダーを使っている人はGeminiの方が他の予定と連携しやすく、ChatGPTを仕事でも使っている人はそのままの流れで献立作成にも使い回せる、という程度の違いで選んで問題ありません。料金やプラン内容は変更されることがあるため、契約前に必ず公式サイトで最新情報を確認してください。

## 手順1:条件シートを作ってAIに渡す

いきなりチャットに条件を書き連ねるより、先に「条件シート」としてメモにまとめておくと、毎週使い回せて楽になります。以下の項目を埋めてみてください。

```
【人数】大人2人・子ども1人
【期間】月曜〜日曜の7日分
【対象の食事】夕食のみ
【1食あたりの予算】800円以内
【好きな食材・料理】鶏肉、豆腐、和食多め
【避けたい食材】パクチー、辛すぎる料理
【冷蔵庫に余っている食材】キャベツ半玉、卵6個、ひき肉200g
【その他条件】同じ食材を数日に分けて使い回したい、平日は15分以内で作れるものがいい
```

この条件シートさえ作っておけば、来週以降は数値や食材名を書き換えるだけで使い回せます。メモアプリやGoogle Keepに保存しておき、毎週日曜の夜に「冷蔵庫に余っている食材」と「今週の予定(外食の有無など)」の2項目だけ更新してコピペする、という運用にすると、ほぼ考えずに毎週同じ流れで献立作成を回せるようになります。

項目を埋めるのが面倒に感じる場合は、最初の数週間だけ丁寧に作り込み、あとは前の週の条件シートをコピーして数字と食材名だけ直す、という使い方でも十分です。完璧な条件シートを最初から目指す必要はありません。

ChatGPTには会話の前提条件を覚えさせる「カスタム指示」、Geminiにも同様の設定機能があります。家族構成や苦手な食材のように毎回変わらない条件はここに登録しておくと、条件シートに書く項目を減らせて、さらに手間が省けます。ただし、これらの設定も入力した内容がサービス側に保存される仕組みのため、次の章で触れる個人情報の扱いには注意してください。

## 手順2:1週間分の献立を作るプロンプト例

条件シートの内容をそのままプロンプトに貼り付けて、ChatGPTやGeminiに投げてみましょう。

```
あなたはプロの栄養士兼料理人です。
以下の条件に従って、1週間分(月〜日)の夕食の献立を提案してください。

【人数】大人2人・子ども1人
【1食あたりの予算】800円以内
【好きな食材・料理】鶏肉、豆腐、和食多め
【避けたい食材】パクチー、辛すぎる料理
【冷蔵庫に余っている食材】キャベツ半玉、卵6個、ひき肉200g
【その他条件】
・同じ食材を数日に分けて使い回してください
・平日は調理時間15分以内のメニューにしてください
・栄養バランス(主食・主菜・副菜)を意識してください

出力は以下の形式でお願いします。
曜日/料理名/使用する主な食材/調理時間の目安
```

実際、人数や期間、予算を指定すれば、条件に合った提案が返ってきやすくなるため、条件はできるだけ具体的に書くのがポイントです。出力された献立に気になる料理があれば「火曜日だけ別の案を3つ出して」のように追加で聞き直せば、部分的な修正もその場でできます。

家族構成によって条件は変わります。一人暮らしで作り置き中心にしたい場合は「1食分ではなく2〜3食分まとめて作れるメニューにしてください」、お弁当も用意したい場合は「翌日のお弁当に詰めやすいおかずを1品含めてください」、ダイエット中なら「1食あたり500kcal前後に抑えてください」のように、その他条件の欄に一文足すだけで対応できます。最初から細かく条件を書き込みすぎず、まず大まかに出してもらってから気になる部分だけ追加で指定していく進め方の方が、やり取りはスムーズです。

野菜中心にしたい、肉や魚を使わない日を作りたいといったリクエストにも、「週に2日はベジタリアンメニューにしてください」のように条件シートに一行加えるだけで対応できます。AIは条件の数が増えても柔軟に組み合わせてくれるので、家族それぞれの希望を遠慮せずに伝えてみるとよいでしょう。

## 手順3:献立から買い物リストに変換するプロンプト例

献立が決まったら、同じ会話の中で続けて買い物リストへの変換を依頼します。会話の履歴を引き継げるツールなら、献立を再送する必要はありません。

```
上記の1週間分の献立に必要な食材を、買い物リストにまとめてください。

条件:
・家にある食材(キャベツ半玉、卵6個、ひき肉200g)は差し引いて、
 追加で買う分だけをリストにしてください
・カテゴリ別(肉・魚/野菜/卵・乳製品/調味料/その他)に分けてください
・おおよその購入量(個数・g・パックなど)も添えてください
・スーパーで買い忘れがないよう、チェックボックス形式で出力してください
```

出力形式を「チェックボックス形式」と指定しておくと、そのままスマホのメモアプリに貼り付けて、買い物中にチェックを入れながら使えます。家族で買い物リストを共有したい場合は、出力結果をLINEのメモやTodoアプリにコピーすると便利です。Google Keepのように家族で共有できるメモアプリを使えば、仕事帰りにどちらかが買い物に寄る、といった分担もしやすくなります。

買い物リストを作るときのちょっとしたコツとして、「スーパーで買うもの」と「ドラッグストアで買うもの(日用品など)」のように、立ち寄る店舗別に分けて出力してもらうこともできます。普段の買い物動線に合わせて指定しておくと、リストを見ながら迷わず売り場を回れます。

ネットスーパーを利用している場合は、「出力結果をそのままネットスーパーの検索窓に入力しやすいように、食材名だけをシンプルな一般名称(商品名ではなく一般名)で出してください」と条件を加えておくと、検索のたびに言い換える手間が減ります。紙のメモで管理したい人は、「A4用紙1枚に収まる分量で、文字サイズを意識して簡潔にまとめてください」と伝えれば、印刷してそのまま冷蔵庫に貼れる形式に近づけられます。

## 手順4:余り物や気分に合わせて献立をアレンジする

1週間の途中で予定が変わったり、新しい食材が手に入ったりすることもあります。その場合は、最初の献立全体を作り直すのではなく、部分的に聞き直すと手間が省けます。

```
水曜日の献立だけ変更したいです。
冷蔵庫に鮭の切り身が2切れ余っています。
和食で、調理時間20分以内のメニューに差し替えてください。
他の曜日の献立と食材がなるべく被らないようにしてください。
```

同様に「今週は外食が1回増えたので、土曜日の献立を1品減らして、栄養バランスを保ったまま簡単なワンプレートメニューに変更してください」のように、理由と条件を一文で伝えるだけでも対応してもらえます。

このように「変更したい日」「理由」「条件」を短く伝えるだけで、AIはすでに作った献立全体の文脈を踏まえて調整してくれます。一から聞き直すより早く、ズレも少なくなります。

急な来客で人数が増えた、子どもの体調が悪くて消化の良いものにしたい、といった場合も同じ考え方で対応できます。

```
今夜、大人が1人増えて3人分になりました。
量を1.5倍にした場合の分量と、
買い足す食材があれば教えてください。
```

このように、献立そのものを作り直すのではなく「増える・減る・変わる」部分だけを伝える癖をつけておくと、毎回ゼロから条件を打ち込む手間がなくなります。

## 使うときに気をつけたい注意点

便利な一方で、いくつか注意しておきたい点があります。AIはあくまで提案をしてくれる便利な相談相手であり、最終的な判断や確認は必ず自分自身で行うようにしましょう。

- **栄養価の数値は目安として扱う**:AIが示すカロリーや栄養バランスは概算であり、医療・療養食など厳密な管理が必要な場合は、必ず栄養士や医師に相談してください。
- **食材アレルギー情報は自己責任で最終確認する**:AIへの伝え忘れや誤解で、アレルギー食材が紛れ込む可能性があります。出来上がったレシピは必ず自分の目で確認してから調理してください。
- **個人情報はできるだけ入力しない**:家族の氏名、住所、通院歴、子どもの詳しい情報などをそのままAIに入力するのは避けましょう。「子ども1人」「大人2人」程度の抽象的な情報で十分に献立は作れます。
- **価格情報は地域や店舗で変わる**:AIが提示する「1食800円」などの目安は一般的な相場であり、実際の価格は地域やスーパーによって差があります。買い物リストの金額はあくまで参考程度に考えてください。
- **料金プランは変更されることがある**:本記事のChatGPT・Geminiの料金は2026年10月時点の情報です。利用前に必ず公式サイトで最新の料金とプラン内容を確認してください。
- **出力をそのまま鵜呑みにしない**:AIは文章としてもっともらしい回答を作るのが得意な一方で、分量や手順に誤りが混じることもあります。特に火を使う工程や加熱時間は、出来上がった献立をそのまま信じず、普段使っているレシピサイトと見比べる習慣をつけると安心です。
- **無料版の利用回数には上限がある場合がある**:サービスや時期によって、無料版は一定時間内のやり取り回数に制限がかかることがあります。毎週使い続けて物足りなさを感じたら、有料プランへの切り替えを検討してください。

## まとめ

AIに1週間分の献立と買い物リストをまとめて作ってもらう方法は、次の4ステップに集約できます。

1. 人数・予算・好み・冷蔵庫の余り物などを「条件シート」としてまとめる
2. その条件をそのままプロンプトに貼り付けて、1週間分の献立を出してもらう
3. 出来上がった献立を「買い物リストに変換してください」と頼み、カテゴリ別・チェックボックス形式で受け取る
4. 途中で予定が変わったら、変更したい日・理由・条件だけを伝えて部分的に調整してもらう

ChatGPTもGeminiも無料版から試すことができ、まずはこの記事のプロンプトをそのままコピペして使ってみてください。慣れてきたら条件シートの項目を増やしたり、ダイエットや作り置きなど自分の生活スタイルに合わせた条件を加えたりすることで、毎週の「今日何作ろう」を考える時間を、少しずつ減らしていけるはずです。
