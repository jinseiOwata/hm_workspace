家計簿アプリで記録はしているけれど、「結局どこを削ればいいのか分からない」「振り返りをする時間がなくて記録しっぱなしになっている」という人は多いのではないでしょうか。家計簿は「つける」こと自体がゴールになりがちですが、本当に大事なのはそのあとの「振り返り」と「改善」です。そして、この振り返り作業こそ、生成AIが最も得意とする領域のひとつです。

ChatGPTやClaudeのような対話型AIは、大量の数字の中からパターンを見つけ出し、人が気づきにくい偏りを指摘するのが得意です。「先月より外食費が増えている」「使っていないサブスクが複数ある」といったことも、手作業で集計するより圧倒的に早く、しかも客観的に洗い出してくれます。この記事では、手元の家計簿データをAIに読み込ませて、具体的な節約ポイントを洗い出す方法を、実際にそのまま使えるプロンプト付きで、準備段階から行動に移すところまで解説します。

## この記事でわかること

- 家計簿アプリやExcelのデータをAIに読み込ませる準備の仕方
- ChatGPTやClaudeにそのまま使える分析プロンプトのテンプレート
- 分析結果を「行動」に変えるためのコツ
- 家計データをAIに入力する際に気をつけたいセキュリティ上の注意点

## 準備するもの:家計簿データをCSVかテキストにする

AIに分析させる第一歩は、データを「読み込める形」にすることです。家計簿アプリを使っている場合、多くのアプリにCSVやExcel形式でのエクスポート機能があります。マネーフォワードMEやZaimなどの家計簿アプリでは、利用明細を期間指定してCSVで書き出せる機能が用意されているので、まずはアプリの設定メニューからエクスポート機能を探してみましょう。アプリによってはエクスポートがプレミアム会員限定の機能になっている場合もあるため、自分が使っているプランでエクスポートできるかどうかは事前に確認しておくと手戻りがありません。

Excelやスプレッドシートで自己管理している人は、そのままシートをCSVやExcel形式で保存すれば準備完了です。GoogleスプレッドシートやMicrosoft Excelで管理している場合は、シート単位でエクスポートしておくと、後述するAIツールへのアップロードがスムーズになります。

紙の家計簿やレシートしかない場合は、無理にアプリに入力し直さなくても大丈夫です。スマホで撮影したレシートの写真をAIに直接読み込ませて、日付・店名・金額をテキスト化してもらうことも可能です。画像を読み込めるタイプのAIチャットであれば、「このレシートの画像から、日付・店名・金額・品目をCSV形式で書き出してください」と頼むだけで、表形式のデータに変換してくれます。何十枚もレシートがある場合は、1回のやり取りで数枚ずつ処理し、出てきたCSVを1つのファイルにまとめていくと作業がしやすくなります。

### データを整える際のチェックポイント

1. 最低でも「日付・金額・カテゴリ(または店名)」の3項目は揃える
2. 期間は直近1〜3ヶ月分あると傾向が見えやすい
3. ファイル形式はCSVが扱いやすいが、Excelファイルのままアップロードできるツールも多い
4. 口座名や個人を特定できる名前が入っている場合は、分析前に削除・置き換えをしておく

CSVが用意できない場合は、以下のようにテキストで手入力した一覧をそのままAIに貼り付けるだけでも分析は始められます。

```
日付,金額,カテゴリ,内容
2026/09/01,-1200,食費,スーパー
2026/09/02,-450,カフェ,コーヒー
2026/09/03,-9800,通信費,スマホ代
2026/09/05,-3200,娯楽,サブスク
```

## 手順1:AIチャットに家計簿データを読み込ませる

ChatGPTやClaude、Geminiなどの対話型AIには、ファイルをアップロードして内容を読み取らせる機能があります。CSVファイルをそのままドラッグ&ドロップでアップロードし、「このファイルを分析して」と伝えるだけで、AI側が表形式のデータとして認識し、合計や平均などの集計もその場で計算してくれます。ChatGPTやClaudeには、アップロードしたデータに対してグラフ作成や計算処理を行う機能が備わっているため、「カテゴリ別の支出を棒グラフにして」といった依頼もそのまま通ることが多いです。

ファイルアップロードがうまく読み込まれない場合や、短期間のデータだけを試したい場合は、先ほどのようなCSV形式のテキストをチャット欄に直接貼り付けても問題ありません。ただし、一度に貼り付けられる文字数には上限があり、ツールやプランによって上限は異なります。数ヶ月分をまとめて貼り付けるとエラーになったり、途中で読み込みが止まってしまったりすることがあるため、まずは1ヶ月分など小さい単位で試し、慣れてきたら期間を伸ばしていくのが安全です。

また、何度もやり取りを重ねて同じデータについて深掘りしたい場合は、ChatGPTの「プロジェクト」機能やClaudeの「Projects」機能のように、特定のファイルを紐づけたまま会話を続けられる機能を使うと、毎回ファイルを貼り直す手間が省けて便利です。こうした機能は執筆時点でプランによって使える範囲が異なることがあるため、気になる方は利用中のサービスの公式サイトで最新の提供状況を確認してみてください。

### どのAIツールを選べばいい?

「どのAIを使えばいいか分からない」という方は、まず自分が普段使い慣れているチャットAIで試してみるのが一番です。ChatGPT・Claude・Geminiのいずれも、CSVファイルの読み込みや集計・グラフ化に対応しており、家計簿分析という用途であれば大きな差は出にくいというのが実感です。強いて言えば、Geminiは普段からGoogleスプレッドシートを家計簿に使っている人との相性がよく、ChatGPTとClaudeはファイルアップロード後の深掘り質問への応答が安定している印象があります。無料プランでも基本的な分析は試せることが多いので、まずは無料の範囲で使ってみて、より長い会話やファイル連携が必要になったタイミングで有料プランを検討するとよいでしょう。料金や利用上限は改定されることがあるため、契約前に必ず各社の公式サイトで最新情報を確認してください。

## 手順2:そのまま使える分析プロンプト集

データを読み込ませたら、次は「何を聞くか」が重要です。漠然と「分析して」と頼むよりも、目的を具体的に伝えたほうが、実用的な回答が返ってきます。以下に、家計の節約ポイントを見つけるための代表的なプロンプトを紹介します。

### プロンプト例1:支出全体の傾向をつかむ

まずは大まかな全体像を把握するための質問です。

```
あなたはファイナンシャルプランナーです。
添付した家計簿データ(CSV)を分析し、以下を教えてください。

1. カテゴリ別の支出合計と、支出全体に占める割合(高い順)
2. 先月と比較して増減が大きいカテゴリとその金額差
3. 一般的な家計の支出割合と比べて、偏りが大きいと思われる項目
4. 上記を踏まえた、優先的に見直すべきカテゴリ上位3つ

数値は表形式でまとめ、専門用語は使わず平易な言葉で説明してください。
```

### プロンプト例2:固定費の見直し提案

固定費は一度見直すと効果が長く続くため、優先的にチェックしたいポイントです。

```
このデータの中から、通信費・サブスクリプション・保険料・家賃など
「毎月ほぼ同じ金額が発生している固定費」を抽出してください。

それぞれについて、
- 一般的な相場と比べて高いと思われるか
- 見直しや解約を検討する価値がありそうか
- 見直した場合の年間の節約見込み額(概算でよい)

を表にまとめてください。断定的な金額保証はせず、あくまで目安として示してください。
```

### プロンプト例3:無駄遣いになりやすい支出を見つける

コンビニやカフェなど、少額だが積み重なりやすい支出をあぶり出すプロンプトです。

```
この家計簿データの中から、1回あたりの金額は小さいものの
回数が多く積み重なっている支出(例:コンビニ、カフェ、飲料の自動販売機など)
を抽出し、月間・年間の合計金額に換算してください。

その上で、
1. 完全にやめるのではなく「回数を半分に減らした場合」の節約額
2. 代替手段(自炊・まとめ買いなど)を1〜2個提案してください。
```

### プロンプト例4:来月の予算案を作ってもらう

分析結果をもとに、次の行動につなげるプロンプトです。

```
今回の分析結果を踏まえて、来月の予算案を作成してください。

条件:
- 食費・日用品費は現実的に無理のない範囲で5〜10%削減
- 固定費は見直し候補として提示した項目を反映
- 娯楽費はゼロにはせず、ストレスなく続けられる金額に調整
- カテゴリごとの予算額を表形式で提示し、
  達成のための具体的な行動も1行ずつ添えてください。
```

### プロンプト例5:3ヶ月分のデータで変化を追う

複数月のデータがある場合は、推移を見ることでより実践的な提案を引き出せます。

```
過去3ヶ月分の家計簿データを比較し、
増加傾向にあるカテゴリと減少傾向にあるカテゴリをそれぞれ挙げてください。
増加傾向にある項目については、考えられる原因の仮説も合わせて提示し、
来月以降に注意すべきポイントを3つにまとめてください。
```

## 分析結果を「行動」に変えるコツ

AIが出してくれる分析や提案は、あくまで現状のデータから導かれる一つの見方にすぎません。そのまま鵜呑みにするのではなく、次のようなステップで自分の生活に落とし込むことが大切です。

1. **提案の中から「今月すぐできること」を1つだけ選ぶ** - 一度に全部変えようとすると続きません。まずはサブスクの解約など、着手しやすいものから始めましょう。複数の提案が出てきたときは、「この中で一番効果が大きく、かつ一番手間がかからないものはどれ?」とAIに優先順位をつけてもらうのも有効です。
2. **AIに「なぜその提案をしたのか」を聞き返す** - 根拠を確認することで、自分の支出パターンへの理解が深まります。「この金額はどのデータから計算しましたか」と聞き返すと、提案の裏付けを確認でき、見当違いの提案を見抜きやすくなります。
3. **翌月また同じようにデータを読み込ませて比較する** - 一度きりではなく、月次の習慣にすることで変化が数字として見えてきます。「先月と比較して何が改善し、何が改善していないか」を聞くプロンプトを毎月使い回せば、振り返りの型をそのまま定着させられます。
4. **AIの提案に違和感があれば採用しない** - 家族構成やライフスタイル、ライフイベントなど、データだけでは分からない事情もあります。最終判断は自分で行いましょう。たとえば「教育費だから削れない」「来月は冠婚葬祭で出費が増える予定」といった背景は、自分からAIに伝えない限り考慮されません。
5. **小さな成功体験を記録しておく** - 「サブスクを1つ解約できた」「外食の回数を減らせた」など、実際にできたことをメモしておくと、翌月以降にAIへ伝える材料になり、より精度の高い提案を引き出せます。

## 個人情報・セキュリティ面での注意点

家計簿データには、口座名や勤務先、家族の名前など、個人を特定できる情報が含まれていることがあります。AIに読み込ませる前に、次の点を必ず確認してください。

- **口座番号やクレジットカード番号、パスワードは絶対に入力しない** - 分析に不要な情報は事前に削除しておきましょう。
- **店名や摘要欄に個人名が入っていないか確認する** - 振込先の個人名などが含まれる場合は、マスキングするか削除してから読み込ませます。
- **利用するAIサービスのデータの取り扱い方針を確認する** - 入力したデータが学習に利用されるかどうかは、サービスやプラン、設定によって異なります。会話履歴やファイルの保存・学習利用に関する設定は、利用前に各サービスの公式ヘルプページで確認しておくと安心です。
- **職場のPCや共有アカウントでは実行しない** - 個人の家計情報は、プライベートな環境・アカウントで扱うようにしましょう。家族で共有しているデバイスの場合も、ログインアカウントが自分専用になっているかを確認しておくと安心です。
- **勤務先や取引先が特定できる情報は伏せる** - 給与明細を一緒に分析したい場合、会社名や部署名が入っていると不要なリスクになります。「会社名」の部分は「勤務先」などの一般的な表記に置き換えてから入力しましょう。

AIはあくまで「分析の壁打ち相手」であり、入力したデータを完全に安全に管理してくれる保証はありません。心配な場合は、金額とカテゴリだけを抽出し、店名や個人名の列はあらかじめ削除してから分析させる方法が有効です。たとえば「スーパーA」「カフェB」のように店名を記号に置き換えても、カテゴリ別の集計や傾向分析という目的であれば十分に実用的な結果が得られます。少しの手間で安心感が大きく変わるので、継続的に使う予定なら最初にテンプレート化しておくのがおすすめです。

## こんな人にはAI家計簿分析がおすすめ

- 家計簿はつけているが、分析や振り返りまで手が回っていない人
- 「何となく出費が多い気がする」を数字で確認したい人
- 固定費の見直しをしたいが、何から手をつけていいか分からない人
- 毎月の予算立てをもっと効率化したい人

逆に、1回分析して終わりにしてしまうと効果は限定的です。月次の習慣として続けることで、AIとのやり取りの精度も上がり、自分の支出パターンに合った提案が返ってくるようになります。慣れてきたら、「毎月25日に先月分のCSVを読み込ませて振り返る」のようにスケジュールを決めてしまうと、家計簿の振り返りそのものを仕組み化できます。

## まとめ

家計簿を「つけて終わり」にせず、AIに分析させることで、自分では気づきにくい支出の偏りや固定費の見直しポイントが見えてきます。必要なのは特別なスキルではなく、CSVやテキストに整えた数ヶ月分のデータと、本記事で紹介したようなプロンプトだけです。今日お手持ちの家計簿アプリを開いて、直近1ヶ月分のデータをエクスポートするところから始めてみてください。

はじめから完璧な分析を目指す必要はありません。まずは「プロンプト例1」で全体傾向をつかみ、気になったカテゴリだけ深掘りしていく、というスモールスタートで十分です。ただし、AIの提案はあくまで現状のデータから導かれた一つの参考情報であり、断定的な効果を保証するものではありません。個人情報の取り扱いには十分注意しながら、自分や家族の生活スタイルに合った形で、無理のない範囲で取り入れていきましょう。
