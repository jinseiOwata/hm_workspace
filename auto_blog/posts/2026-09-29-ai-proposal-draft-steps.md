## この記事でわかること

- 生成AIに企画書の「たたき台」を作らせる具体的な手順（壁打ち→構成案→本文生成→仕上げの4ステップ）
- そのままコピペで使えるプロンプトテンプレート
- 出力の精度を上げるための指示のコツ
- 生成AIに企画書作成を任せるときに気をつけたいリスクと注意点

企画書作成でいちばん時間がかかるのは、実は「白紙のページに最初の一文を書く」瞬間です。生成AIは、この「ゼロから1」を作る部分を強力にサポートしてくれます。ただし、AIが作るのはあくまで「たたき台」であり、そのまま提出できる完成品ではありません。本記事では、ChatGPTを例に、たたき台を作る具体的な手順とプロンプト、注意点を整理します。

## 生成AIに企画書を作らせる前に知っておきたいこと

生成AIは、情報の整理・構成案の作成・文章のドラフト化が得意です。一方で、社内の最新実績や競合の正確な数値、法規制の細かい要件などは知らないか、古い情報のまま生成してしまうことがあります。そのため、生成AIの役割は「たたき台」までと割り切り、数値・固有名詞・最終判断は必ず人間が確認するという前提で使うのが安全です。

ChatGPTについては、無料プランに加えて有料プランが用意されており、2026年時点ではPlusプランが個人向けの標準プランとして位置づけられています。ChatGPT Plusは、OpenAIが提供するChatGPTの個人向け有料プランです。2026年7月現在、フラグシップモデルであるGPT-5.5を活用でき、Deep Researchや画像生成、コーディングエージェントCodexといった高度な機能が月額3,000円で利用できるサービスとして、ビジネスパーソンを中心に利用者が拡大しています。また、チーム利用向けのプランも用意されており、Businessプラン（2025年8月29日に旧Teamプランから名称変更）は、チームや部門単位での利用を想定した法人向けプランです。Plus相当以上の機能に加え、ユーザー管理や専用ワークスペース、基本的なコンプライアンス対応が追加されています。

企画書のたたき台作りだけであれば無料プランでも十分試せますが、資料の分量が多い場合や画像生成・ファイル読み込みを併用したい場合は、有料プランの検討価値があります。なお、ChatGPT以外にもGeminiやClaude、Copilotなど複数の生成AIサービスがあり、料金や機能は各社が随時改定しています。契約前には必ず公式サイトで最新の料金・機能を確認してください。

## 準備:素材集めとツールの決め方

企画書のたたき台をきれいに作るコツは、「AIに丸投げしない」ことです。以下の3点だけ先に準備しておくと、後の作業が一気にラクになります。

1. **企画の目的とゴール**（何のために・誰に向けて・何を決めてもらいたいか）
2. **手元にある素材**（過去の類似企画書、市場データ、社内で決まっている制約条件など）
3. **企画書のフォーマット**（社内テンプレートがあればその見出し構成、なければ「課題→提案→効果→実行計画」などの基本型）

これらをテキストファイルやメモにまとめておき、チャットの最初に貼り付けられる状態にしておきましょう。個人情報や取引先の非公開情報、社外秘の数値などは、そのままAIに入力しないよう注意が必要です（詳しくは後述の「注意点」で解説します）。

## 手順1〜4:壁打ちから完成たたき台までの4ステップ

ここからは、実際に生成AIとやり取りしながら企画書のたたき台を作る手順です。ChatGPTを例にしていますが、GeminiやClaudeなど他の生成AIでも同じ流れで応用できます。

### 手順1:目的とテーマを伝えて「壁打ち」する

いきなり本文を書かせるのではなく、まずはAIを壁打ち相手にして、企画の切り口を広げます。

```
あなたは企画立案の壁打ち相手です。
以下のテーマについて、切り口を5つ提案してください。
それぞれ「想定される効果」「実現の難易度（高/中/低）」も添えてください。

テーマ：[例：新入社員向けオンボーディング施策の企画]
背景：[例：離職率が高く、入社3ヶ月以内の退職が多い]
制約：[例：追加予算はほぼゼロ、実施は人事部2名で対応]
```

出てきた案の中から自分が良いと思うものを選び、次のステップに進みます。

### 手順2:構成案（骨子）を作らせる

切り口が決まったら、企画書の見出し構成（骨子）を作らせます。ここでいきなり本文を書かせると、全体のバランスが悪くなりがちです。

```
以下の企画テーマで、企画書の構成案（見出しレベル）を作ってください。
本文はまだ書かず、見出しと各見出しで書く内容の要点（箇条書き2〜3個）だけにしてください。

テーマ：[選んだ切り口]
提出先：[例：部長・役員向け]
希望フォーマット：課題→提案内容→期待効果→スケジュール→必要リソース→リスクと対策
```

この段階で見出しの過不足や順番を人間がチェックし、必要なら「〇〇の見出しは不要」「△△を追加して」と指示して調整します。

### 手順3:見出しごとに本文をドラフト生成する

構成案が固まったら、見出しごとに本文を生成させます。一気に全部作らせるより、見出し単位で作らせたほうが、修正指示が出しやすくなります。

```
先ほど決めた構成の「課題」セクションの本文を書いてください。
条件：
・文体は「です・ます調」のビジネス文書
・文字数は300〜400字程度
・具体的な数値が必要な箇所は [要確認：〇〇のデータ] のようにプレースホルダーで示す
・断定的な表現ではなく、提案段階であることが伝わる書き方にする
```

「数値はプレースホルダーにする」という指示を入れておくと、AIが不確かな数字をそれっぽく作ってしまう（いわゆるハルシネーション）のを防ぎやすくなります。生成された本文に埋め込まれたプレースホルダーは、必ず自分で正しい数値に置き換えてください。

### 手順4:通し読みして「たたき台」として整形する

全セクションが揃ったら、一度通しで生成させて全体のトーンを揃えます。

```
これまでの各セクションの内容をつなげて、企画書のたたき台として整えてください。
・見出し番号を振る
・セクション間で表現の重複があれば削る
・全体のトーンを統一する
・最後に「未確定事項リスト（要確認事項）」を箇条書きで追加する
```

「未確定事項リスト」を最後に出させておくと、人間がレビューすべきポイントが一目でわかり、レビュー漏れを防げます。

## 精度を上げるための追加プロンプト例

たたき台の質をもう一段上げたいときは、以下のような「役割指定」や「批判的レビュー」のプロンプトも有効です。

```
あなたは経験豊富な企画部門の管理職です。
今書いた企画書のたたき台を、以下の観点で厳しくレビューしてください。
・提案内容と期待効果の因果関係が弱い箇所
・具体性が足りず、読み手が判断に迷う箇所
・反対意見が出そうな箇所とその想定反論

指摘だけでなく、改善案も一緒に提示してください。
```

このように「あえて批判させる」プロンプトを挟むと、自分では気づきにくい論理の穴やツッコミどころを事前に洗い出せます。役員会議やクライアント提案の前に一度通しておくと、レビューの質が上がります。

## 生成AIで企画書を作るときの注意点

生成AIによる企画書作成は便利な反面、いくつかのリスクを理解した上で使う必要があります。

- **機密情報・個人情報を入力しない**：取引先の非公開データ、顧客の個人情報、社外秘の数値などをそのままチャットに貼り付けるのは避けましょう。会社によっては社内規定で生成AIへの入力自体が制限されている場合もあるため、事前にルールを確認してください。
- **数値・固有名詞は必ず裏取りする**：生成AIは、もっともらしいが実際には存在しない統計や事例を出すことがあります。市場データや競合情報は、AIの出力を鵜呑みにせず一次情報で確認しましょう。
- **著作権・引用のルールを守る**：他社の資料や記事の文章をそのまま貼り付けて「要約して」と指示すると、意図せず既存の著作物に近い表現が出力に含まれることがあります。参考にする場合も、自分の言葉で書き直すことを意識してください。
- **「AIが作った」を隠さない社内ルール確認**：企画書の作成過程でAIを使ったことを開示するかどうかは、組織やプロジェクトによってルールが異なります。事前に確認しておくとトラブルを避けられます。
- **最終責任は人間にある**：たたき台としての完成度が高くても、意思決定に使われる企画書の内容は、最終的に提出者が責任を持って確認する必要があります。

## まとめ

生成AIを使った企画書のたたき台作りは、「壁打ち→構成案→セクションごとのドラフト→通し整形」という4ステップに分けると、無理なく進められます。ポイントは、いきなり全文を書かせるのではなく段階的に指示を出すこと、そして数値や固有名詞はプレースホルダー化して後から自分で確認することです。生成AIはあくまで「最初の一文を書く」負担を軽くしてくれるパートナーであり、最終的な内容の正確性や機密情報の取り扱いについては、これまで通り人間がしっかりチェックする姿勢を忘れないようにしましょう。
