## この記事でわかること

- ExcelのVLOOKUPやXLOOKUP、IF関数の組み合わせをAIに考えてもらう具体的な手順
- VBAマクロを書いたことがなくても、AIに依頼して自動化コードを作ってもらう方法
- そのままコピペで使えるプロンプトのテンプレート
- AIが書いた数式・マクロを実行する前に必ず確認すべきポイント
- 業務データをAIに入力するときに気をつけたいリスク

「複雑な関数を組みたいけど、どの関数を組み合わせればいいかわからない」「毎月同じ作業を自動化したいけどVBAは書けない」——そんな悩みは、ChatGPTやExcelに搭載されているAI機能に相談すれば、驚くほどあっさり解決することがあります。

これまでは、関数を1つ組むだけでもネットで用語を検索し、複数のサイトを見比べながら試行錯誤する必要がありました。マクロにいたっては、書籍を1冊読んでからでないと手を出しづらいと感じていた人も多いはずです。AIに相談するスタイルに切り替えると、この「調べる時間」の大部分を短縮できます。もちろん、AIの回答をそのまま信用してよいわけではなく、確認すべきポイントもあります。この記事では、関数とマクロの両方について、実際にAIへ渡すプロンプトの書き方と、生成されたコードを安全に使うための手順を具体的に紹介します。

## Excelの「関数がわからない」「マクロが書けない」をAIで解決する

Excelの関数は数百種類あり、ネストして組み合わせる使い方まで覚えるのは大変です。マクロ(VBA)にいたっては、そもそもプログラミングの知識が前提になるため、独学でハードルを感じている人も多いはずです。

AIチャットに「やりたいこと」を日本語で説明するだけで、関数の組み合わせやVBAコードの叩き台を提案してもらえます。ポイントは、AIに丸投げするのではなく、次の3ステップを踏むことです。

1. **やりたいことを具体的に言語化する**(どの列の、どんな条件で、何をしたいか)
2. **AIに関数・コードを作ってもらう**
3. **小さいデータで動作確認してから本番に使う**

この流れさえ守れば、関数もマクロも「知らないから諦める」状態から抜け出せます。特に効果を感じやすいのは、次のような場面です。

- 毎月の売上集計で、条件が少しずつ違う表を何枚も作っている
- 複数シートに分かれたデータを、手作業でコピペしながら1枚にまとめている
- 「本当はもっと効率化できるはずだけど、関数もマクロも詳しくないので諦めていた」作業がある

こうした作業は、AIに「今やっている手順」をそのまま説明するだけで、関数1本、あるいは数十行のマクロに置き換えられることが少なくありません。まずは自分の業務の中から、一番時間を取られている単純作業を1つ思い浮かべながら読み進めてみてください。

### どのAIを使う?ChatGPT・Copilot・Geminiの使い分け

Excel作業をAIに手伝ってもらう方法は、大きく分けて2つあります。

- **チャット型AI(ChatGPT、Geminiなど)に相談する方法**
  Excelとは別のブラウザやアプリでAIチャットを開き、やりたいことを説明して関数やVBAコードを出してもらい、Excel側にコピペする使い方です。無料プランでも十分に対応できる場面が多く、まず試すならこちらが手軽です。

- **Excelに組み込まれたAI機能(Microsoft 365 Copilotなど)を使う方法**
  Excelの画面内からAIに直接指示を出し、シート上のデータを参照しながら数式や分析を提案してもらえます。ただし、利用にはMicrosoft 365の対象プランへの加入が必要な場合が多く、対応機能や料金は変更されることがあるため、契約前に必ずMicrosoft公式サイトで最新の対象プランと料金を確認してください。

どちらを使うにしても、基本的なプロンプトの書き方は共通しています。まずはチャット型AIで慣れておくと、後からExcel内蔵のAI機能に移行してもスムーズです。

なお、無料プランと有料プランでは、一度に処理できる文章量や、回答の精度・応答速度に差があることが一般的です。複雑な関数やマクロを何度もやり取りしながら詰めていきたい場合は、有料プランのほうが快適に感じられることもありますが、まずは無料の範囲で試してみて、自分の使い方に合うかどうかを確かめてから検討するのがおすすめです。料金体系やプランの内容は各サービスとも改定されることがあるため、契約前に必ず公式サイトで最新情報を確認してください。

## STEP1 関数をAIに作ってもらう手順とプロンプト例

関数をAIに依頼するときは、次の情報をセットで伝えると精度が上がります。

- 使っている列や範囲(例:A列に商品名、B列に金額)
- 条件の詳細(例:「金額が1万円以上なら」)
- 出したい結果の形(数値なのか、文字列なのか、空欄処理はどうするか)
- 使用しているExcelのバージョン(関数によっては新しいバージョンでしか使えないものがあるため)

### プロンプト例1:条件付きで集計する関数を作ってもらう

```
あなたはExcelの数式の専門家です。
以下の条件に合う数式を作ってください。

- シート「売上」のA列に日付、B列に担当者名、C列に売上金額が入っています。
- 2行目からデータが始まり、最終行は可変です。
- 担当者名が「山田」で、かつ売上金額が10000円以上の行だけを合計したいです。
- 出力先はF2セルで、Excelのバージョンは Microsoft 365(最新)です。

数式そのものと、各部分が何をしているかの簡単な説明もあわせて出力してください。
```

### プロンプト例2:関数のエラーを直してもらう

```
以下のExcel数式を入力したところ「#N/A」エラーが出ます。
原因と修正後の数式を教えてください。

数式:=VLOOKUP(A2,商品マスタ!A:C,3,FALSE)

補足:
- 「商品マスタ」シートのA列は商品コード(文字列)です。
- A2セルには商品コードが半角で入っています。
- 商品マスタのA列にも同じコードがあるはずですが、一致しません。
```

このように「エラーメッセージ」と「前提条件」をセットで伝えると、AIは全角半角の違いや余分なスペースなど、見落としがちな原因まで指摘してくれることがあります。

### 関数を「読み解く」ためにもAIは使える

AIは新しい関数を作ってもらうだけでなく、既存の複雑な数式を解読させる用途にも向いています。前任者が作った数式や、社内の共有ファイルに入っている長いネスト構造の数式を見て「何をしているのか分からない」というときは、数式をそのままコピーして「この数式が何を計算しているか、初心者にもわかるように1ステップずつ説明してください」と依頼するだけで、条件分岐の意味や参照しているセルの役割を1つずつ解説してもらえます。関数を丸ごと引き継いだけれど中身がブラックボックスになっている、というありがちな状況を解消するのに役立つ使い方です。

## STEP2 マクロ(VBA)をAIに書いてもらう手順とプロンプト例

マクロは関数以上に「間違えたときの影響」が大きくなりがちです。ファイルを上書きしたり、複数シートを一括操作したりするコードも書けてしまうため、依頼の仕方と確認の仕方が特に重要になります。

依頼するときは、以下を必ず伝えましょう。

- 何をトリガーに実行したいか(ボタンを押したときか、ファイルを開いたときかなど)
- 対象のシート名・セル範囲
- 「上書き」なのか「別シートに出力」なのか、結果の扱い
- Excelのバージョン(古いバージョンでは使えない構文もあります)

### プロンプト例3:定型作業を自動化するマクロを作ってもらう

```
Excel VBAのマクロを作成してください。要件は以下の通りです。

- 「入力用」シートのA2:A100に社員名、B2:B100に評価点が入っています。
- 評価点が80点以上の社員名だけを、「合格者」シートのA列に上から詰めて出力したい。
- 実行のたびに「合格者」シートの内容は一度クリアしてから書き直す。
- ボタンをクリックして実行する想定のマクロにしてください。

コードには日本語コメントを入れて、初心者でも処理の流れが追えるようにしてください。
```

### プロンプト例4:既存マクロの修正・デバッグを依頼する

```
以下のVBAマクロを実行すると「実行時エラー'9':インデックスが有効範囲にありません」と出ます。
原因と修正版のコードを教えてください。コードは変更せず、まず考えられる原因を3つ挙げてから修正案を出してください。

[ここに現在のマクロのコードを貼り付ける]
```

エラーメッセージをそのまま貼るのがコツです。AIは「シート名が違う」「配列の範囲外を参照している」など、原因の候補を複数提示してくれるので、自分のファイルの状況と照らし合わせて判断できます。

### マクロを依頼するときに追加で伝えると精度が上がること

上記のプロンプトに加えて、次のような情報も伝えると、より実務で使いやすいマクロになります。

- **処理速度への配慮が必要かどうか**:大量の行数(数千〜数万行)を扱う場合は、「画面の再描画を止める」「配列に一度読み込んでから処理する」といった高速化のテクニックを盛り込んでもらえるよう依頼できます。
- **確認メッセージの有無**:実行時に「本当に実行しますか?」という確認ダイアログを出すかどうかも指定できます。誤操作防止のため、削除や上書きを伴うマクロには確認メッセージを入れてもらうのがおすすめです。
- **ショートカットキーやボタンへの割り当て**:マクロの実行方法(ボタン、ショートカットキー、自動実行など)も併せて伝えると、実装まで一気に進められます。

これらは一度に全部伝える必要はなく、最初のたたき台をもらった後に「確認メッセージを追加して」「1万行でも重くならないようにして」と追加で依頼していく形で問題ありません。

## AIが書いたコードを実行前にチェックする3つのポイント

AIが出してくれる関数やマクロは便利ですが、そのまま鵜呑みにするのは避けましょう。特にマクロは「ファイルの削除」「他ブックの上書き」など、取り返しのつかない処理を含むコードが生成される可能性もゼロではありません。実行前に、最低限次の3点を確認してください。

1. **バックアップを取ってから試す**
   元のファイルをコピーしておき、コピーの上でマクロを実行します。特に「Kill」「Delete」「SaveAs」「.Close」といった、ファイル操作系の命令が含まれていないかをざっと目で追いましょう。

2. **小さいテストデータで動作確認する**
   本番データでいきなり実行せず、数行程度のダミーデータで意図通りに動くか確認します。

3. **AIに「このコードの危険な箇所は?」と聞き返す**
   コードを受け取ったら、追加で「このマクロで元データが失われる可能性がある処理はありますか?」と質問してみるのも有効です。AI自身に自己点検させることで、見落としに気づきやすくなります。

### プロンプト例5:生成されたコードの危険箇所を確認してもらう

```
先ほどのマクロについて、実行すると元のシートのデータが
上書き・削除される箇所があれば教えてください。
また、実行前にバックアップを取るべき理由も具体的に説明してください。
```

このひと手間を挟むだけで、「削除」「上書き」「他ブックへの書き込み」といった処理が含まれているかどうかを、コードを読み慣れていない人でも把握しやすくなります。回答の中に少しでも不安な処理が含まれていたら、その部分だけをさらに詳しく質問し、必要であれば「その処理は行わずに、代わりに別シートへコピーする形にしてください」のように、より安全な代替案を依頼しましょう。

## 注意したいリスク:機密情報・個人情報の入力

関数やマクロを依頼する際、つい業務データの実物をそのままコピペしたくなりますが、これは避けるべきです。チャット型AIに入力した内容は、サービスによって学習に利用されたり、外部のサーバーに送信・保存されたりする場合があります。

具体的には、次のような対策を心がけてください。

- 顧客名、社員名、取引先名、金額の実数値などはダミーデータに置き換えてから質問する(例:「山田太郎」→「Aさん」、実際の売上額→「10000」などの丸めた数値)
- 会社名・部署名・システム名など、それだけで組織が特定できる情報も伏せる
- 会社のセキュリティポリシーで生成AIの利用に制限がある場合は、必ずそれに従う
- Excel内蔵のAI機能を使う場合も、どこまでのデータがAI側に送信されるのか、利用規約やヘルプページで確認してから使う

「関数の書き方」や「マクロの構造」を聞くだけなら、実データを見せる必要はほとんどありません。列の意味と条件だけを説明する、という習慣をつけておくと安全です。

また、Excelファイルそのものをアップロードして分析させる機能を使う場合は、より一層の注意が必要です。ファイルを丸ごと渡すと、関係のない列や、意図せず残っていた個人情報・機密情報まで一緒にAIへ渡ってしまう可能性があります。ファイルをアップロードする前に、次のことを確認する習慣をつけましょう。

- 不要な列や、過去のメモ・コメントが残っていないか
- シートが複数ある場合、見せる必要のないシートまで含まれていないか
- そのファイルを外部サービスにアップロードすること自体が、社内規定やお客様との契約(秘密保持契約など)に抵触しないか

判断に迷う場合は、AIに相談する前に上長や情報システム部門に確認するのが安全です。「効率化したい」という気持ちが先走って、うっかり機密情報を送ってしまった、という事態を避けるためにも、少し立ち止まって確認する癖をつけておきましょう。

## よくある失敗パターンと対処法

最後に、AIにExcel作業を任せる際によくあるつまずきと、その対処法を挙げておきます。

- **「いい感じにやって」だけで依頼してしまう**
  → 列名・条件・出したい形を具体的に書くほど、精度の高い答えが返ってきます。曖昧な依頼は曖昧な答えしか生みません。

- **エラーが出たときに、エラーメッセージを見せずに聞いてしまう**
  → 「動きません」ではなく、実際のエラーメッセージと発生条件をそのまま貼り付けましょう。

- **一度で完璧な答えを求めてしまう**
  → 最初の回答が不完全でも、「この部分はこう直したい」と追加で伝えれば、対話を重ねながら精度を上げられます。関数もマクロも、1往復で終わらせずに何度かやり取りする前提で使うのがコツです。

- **バージョン違いに気づかない**
  → 新しい関数(XLOOKUPなど)は、古いバージョンのExcelでは使えないことがあります。自分の環境を伝えるひと言を忘れないようにしましょう。

- **AIの回答をコピペしただけで満足してしまう**
  → 関数やマクロが「動いた」だけで安心せず、想定外のデータ(空欄、文字列と数値が混在したセルなど)が入ったときにも正しく動くかどうか、少し意地悪なテストデータでも確認しておくと安心です。

- **社内共有時に「AIが作った」ことを伝えない**
  → 他の人が引き継いだときに困らないよう、関数やマクロのコメント欄・備考欄に「AIの提案をもとに作成、動作確認済み」といった一言を残しておくと、後任者が原因を調べやすくなります。

- 関数もマクロも、対象範囲・条件・出したい結果をセットで伝えるとAIの回答精度が上がる
- マクロはファイル操作を含む可能性があるため、バックアップとテストデータでの確認を必ず行う
- 実データそのものではなく、ダミーデータに置き換えてからAIに質問する習慣をつける
- 一度のやり取りで終わらせず、エラーメッセージや追加の要望を伝えながら対話的に仕上げていく
