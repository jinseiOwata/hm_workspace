## この記事でわかること

- ChatGPTでYouTube台本をゼロから作るときの、企画〜完成までの5ステップ
- そのままコピペして使える台本作成プロンプトのテンプレート(構成案・フック・本文・タイトル案・推敲)
- 「AIっぽい棒読み台本」にならないための具体的な直し方
- 台本作成でChatGPTに入力してはいけない情報や、公開前に必ず確認すべきこと
- 無料版とPlusプラン、どちらでYouTube台本作りをするべきかの判断基準

YouTube台本は「構成を考える」「セリフに落とし込む」「尺を調整する」という3つの作業が同時に発生するため、ゼロから1本書くのに2〜3時間かかることも珍しくありません。特に初心者のうちは、台本用紙を前に「何から書けばいいかわからない」まま時間だけが過ぎてしまうケースも多いはずです。

ChatGPTにネタ出しと下書きを任せれば、この作業時間を大きく圧縮できます。ただし「台本を書いて」とだけ頼んでも、どこかで見たような無難な内容しか返ってきません。本記事では、企画が何もない状態から公開用の台本に仕上げるまでの手順を、実際に使えるプロンプト付きで紹介します。台本作成に慣れていない方でも、そのままコピペして条件部分だけ書き換えれば使える形にしてあります。

## YouTube台本をChatGPTで作る全体の流れ(5ステップ)

台本作りを一度にChatGPTへ丸投げすると、ありきたりな構成や当たり障りのないセリフしか出てきません。精度を上げるコツは、工程を分けて段階的に指示を出すことです。

1. **企画・構成案を複数出させる**(いきなり本文を書かせない)
2. **採用する構成を選び、見出し(アウトライン)を確定させる**
3. **見出しごとにセリフレベルの台本を書かせる**
4. **冒頭15秒のフックだけを別途強化する**
5. **尺・言葉遣い・禁止表現をチェックして整える**

それぞれの工程を分ける理由は単純で、ChatGPTは一度に処理する情報量が多いほど、内容が浅く平均的になりやすいからです。構成・セリフ・尺調整を同時に頼むと、どの要素も中途半端な仕上がりになりがちですが、工程ごとに分けて指示を出すと、各ステップで「狙った精度」の答えが返ってきやすくなります。

この順番を守るだけで、いきなり「台本を書いて」と頼むより圧倒的に完成度が上がります。慣れてくれば1本あたりの作業時間を体感で半分以下に縮められる人も多いはずです。最初は手順が多く感じても、慣れれば各ステップのやり取りは数分で終わるようになります。以降、各ステップで使うプロンプトを具体的に紹介します。

## 台本作成前に準備する3つの情報

プロンプトを打つ前に、以下の3つだけ決めておきましょう。ここが曖昧だと、ChatGPTは無難な一般論しか返してきません。逆に言えば、この3点さえ明確であれば、台本の精度は大きく変わります。

- **チャンネルのジャンルとターゲット視聴者**(例:30代向け副業解説チャンネル)。誰に向けた話かが曖昧だと、ChatGPTは一般的な説明文しか返してきません。
- **動画の目的**(登録者を増やしたい/特定商品への誘導/再生時間を伸ばしたい、など)。目的によってフックの作り方や台本の締め方が変わります。
- **動画の長さの目安**(ショート60秒、通常動画8分など)。長さを伝えないと、尺調整の段階で大幅な書き直しが発生しやすくなります。

この3点をメモ帳に書き出しておき、プロンプトの冒頭に毎回貼り付けるようにすると、やり取りのたびに説明し直す手間が省けて時短になります。例えば「ジャンル:30代会社員向けの副業・資産形成/ターゲット:投資を始めたいが知識に自信がない会社員/目的:登録者を増やす/長さ:通常動画8分」といった一文を定型メモとして保存しておき、新しい動画の台本を作るたびに「テーマ」の部分だけ書き換えれば、毎回ゼロから条件を説明し直す手間がなくなります。

## 【実践】台本をゼロから作る時短プロンプト5選

ここからは、先ほどの5ステップに対応したプロンプトを順番に紹介します。例として「30代会社員向けの副業・資産形成チャンネル」を想定していますが、【】で囲んだ部分を自分のチャンネル情報に書き換えれば、そのまま別ジャンルの動画にも応用できます。

### 1. 企画・構成案を3パターン出させるプロンプト

いきなり台本本文を求めず、まずは構成のたたき台を複数もらいます。

```
あなたはYouTube構成作家です。
以下の条件でショート/通常動画の構成案を3パターン提案してください。

【チャンネル】30代会社員向けの副業・資産形成チャンネル
【動画テーマ】新NISAを使った積立投資の始め方
【動画の長さ】8分想定
【目的】チャンネル登録者数を増やす

各案には以下を含めてください。
- タイトル案(クリックしたくなるもの)
- 冒頭フックの要約(1行)
- 見出し構成(導入・本編3〜4ブロック・まとめ)
- 想定される視聴維持率が高くなりそうな理由
```

3案を比較し、自分の言いたいことや視聴者の悩みに一番近いものを選びます。どれもしっくりこない場合は「3案のうち2案目の切り口で、もっと具体的な失敗談を入れたバージョンを追加で1つ」のように、気に入った部分を指定して再生成を依頼すると、ゼロから考え直すより早く収束します。

### 2. 見出し(アウトライン)を台本レベルに分解するプロンプト

構成案が決まったら、見出しごとにどんな話をするか箇条書きで分解してもらいます。

```
先ほど選んだ構成案2をベースに、各見出しで話す内容を
箇条書き3〜5個ずつに分解してください。
まだセリフ調にはせず、要点のメモとしてまとめてください。
重複する内容があれば指摘してください。
```

ここで重複や論理の飛躍をチェックしておくと、後工程の手戻りが減ります。この段階でおかしな箇所に気づかずセリフ化まで進めてしまうと、台本の後半になって「さっきも同じ話をした」という修正が発生し、結果的に時短にならないため注意しましょう。

### 3. 冒頭15秒の「フック」を複数案出すプロンプト

YouTubeは冒頭で離脱されるかどうかが再生時間を大きく左右します。フックだけは必ず単独で作り込みましょう。

```
この動画の冒頭15秒で使うフックのセリフを5パターン作ってください。
条件:
- 「え、知らなかった」と思わせる意外性のある一言から始める
- 視聴者の悩み(新NISAどれを選べばいいかわからない)に触れる
- この動画を最後まで見るとどんなメリットがあるかを一言で予告する
- 1パターンあたり3〜4文、話し言葉で
```

5パターンの中から、自分のキャラクターや口調に合うものを選ぶか、良い部分を組み合わせます。フックは動画の顔とも言える部分なので、他のブロックより時間をかけて数パターン比較する価値があります。

### 4. ブロックごとにセリフ台本を書かせるプロンプト

アウトラインが固まったら、ブロックごとに本文を書いてもらいます。一度に全部頼むと冗長になりやすいので、ブロック単位がおすすめです。

```
以下のメモをもとに、動画本編の「本編ブロック1」のセリフ台本を書いてください。

【メモ】
・新NISAのつみたて投資枠と成長投資枠の違い
・初心者がやりがちな失敗(枠を使い切ろうと無理する)

【条件】
- 口調:親しみやすい「です・ます」調、専門用語は一言で言い換える
- 長さ:話して60〜75秒程度の分量
- 視聴者に語りかけるような一人称トーク
- 数字や制度名は必ず正確に、断定しすぎず「〜とされています」も適宜使う
```

残りのブロックも同じ形式で1つずつ依頼すると、トーンが安定します。8分動画であれば本編ブロックは3〜4個程度に分けるのが目安で、1ブロックずつ会話のキャッチボールのように直していくと、全体を一気に書かせるよりも自分の意図に近い仕上がりになります。

### 5. 尺調整とタイトル・サムネ案を仕上げるプロンプト

台本が一通り完成したら、最後に尺調整とタイトル案をまとめて依頼します。

```
完成した台本全体を読み、以下を行ってください。

1. 話した場合の推定秒数をブロックごとに算出
2. 8分(480秒)に収まるよう、冗長な部分を指摘し短縮案を提示
3. クリック率が高くなりそうな動画タイトルを5案
4. サムネイルに入れる短いキャッチコピーを5案
5. 台本中に事実確認が必要そうな数値・制度名があれば一覧化
```

5番の「事実確認リスト」は特に重要です。ChatGPTが提示したタイトル案やサムネコピーも、そのまま採用する前に「煽りすぎていないか」「内容と乖離していないか」を自分の目で確認してから使うようにしましょう。この事実確認リストをどう扱うべきか、次の章で詳しく説明します。

## 「AIっぽい棒読み台本」を直す3つのコツ

ChatGPTの初稿は情報として正しくても、文章としては整っているのに声に出して読むとぎこちない、いわゆる「読み上げ口調」になりがちです。これは書き言葉と話し言葉の違いを意識せずに生成されるためで、以下の指示を追加で投げると改善しやすくなります。

- **「同じ語尾を3回以上続けない」と指定する**(「〜です。〜です。」の連発を防ぐ)
- **「実際に自分が話すように、言い淀みや相槌を少し入れて」と頼む**
- **完成した台本を声に出して読み、詰まった箇所だけChatGPTに「ここを自然な話し言葉に直して」とピンポイント修正する**

例えば、初稿で「新NISAは非課税で運用できる制度です。初心者にもおすすめです。気軽に始められます。」のように単調な文が続いた場合は、「この3文を、友人に話しかけるような自然な話し言葉に直してください。同じ語尾を繰り返さず、間に短い相槌や言い換えを1つ入れてください」とだけ追加で指示すれば、単調さが解消されます。

全文を一度に直させるより、引っかかった一文だけを渡して直させる方が、トーンが崩れずに済みます。

## 台本作成で必ず確認すべき注意点

台本作成を時短できる分、浮いた時間は必ず「公開前の確認作業」に充てましょう。チェックを怠ると、再生数以前に視聴者からの信頼を失うリスクがあります。

- **事実確認は必須**:ChatGPTは制度名や数値をもっともらしく誤って生成することがあります。法律・税制・医療・金融など視聴者の判断に影響する情報は、公式サイトや一次情報で必ず裏取りしてください。
- **個人情報・未公開情報を入力しない**:視聴者から届いた相談内容やスポンサー契約の詳細など、特定個人や企業が識別できる情報はプロンプトに含めないようにしましょう。入力した内容はサービス側の設定によって学習や保存に使われる場合があるため、仮名や伏せ字に置き換えてから相談するのが安全です。
- **他者の台本・歌詞・記事をそのまま貼り付けて「要約して」と頼まない**:著作権のある文章を丸ごと入力したり、生成結果をそのまま公開したりすることは権利侵害につながる可能性があります。参考にする場合は要点だけをメモにしてから渡しましょう。
- **断定表現は人がチェックする**:「絶対に稼げる」「必ず痩せる」のような言い切り表現をAIが提案してきても、そのまま採用せず、景品表示法や薬機法に触れないか確認してください。
- **引用元・出典のメモを残す**:台本中で統計やランキングに触れた場合は、どの情報源から得たかを自分用にメモしておくと、視聴者からのコメントで根拠を聞かれたときにすぐ回答できます。

## 無料版とPlus、どちらで台本作りをすべきか

結論から言うと、どのプランを選ぶべきかは更新頻度と作業スタイル次第です。台本作成だけであれば、無料版のテキストチャットでも十分に試せます。ただし、無料版はアップロード・画像生成・音声・Deep Research・メモリ・Codexには機能別の上限があり、1日に何本も台本を作ったり、長い構成案を何度もやり取りしたりすると、途中で制限に当たることがあります。

| プラン | 月額の目安 | 台本作成での向き不向き |
| --- | --- | --- |
| 無料版 | 0円 | 週1本程度の更新や、まず試してみたい人向け |
| Plus | 3,000円 | 毎週・毎日更新するチャンネル運営者向け |

毎日・毎週の動画制作でChatGPTを使うなら、Plus(月額3,000円)ではDeep Research・プロジェクト・スケジュール済みタスク・カスタムGPT・Codexの利用上限が拡大されるため、台本の修正を何往復もするスタイルには向いています。逆に「月に数本しか動画を出さない」「まずは試したい」という場合は、無料版から始めて物足りなさを感じたタイミングで切り替えれば十分です。料金やプラン内容は変更されることがあるため、契約前に必ず公式サイトの最新情報を確認してください。

## まとめ

ChatGPTでYouTube台本をゼロから作るコツは、「構成案→アウトライン→フック→ブロックごとの本文→尺調整」という順番で、工程を分けて指示を出すことです。一度に台本全体を書かせようとすると当たり障りのない内容になりがちですが、本記事のテンプレートのようにブロック単位・目的単位でプロンプトを分けることで、時短と質の両立がしやすくなります。

ただし、時短できるのはあくまで「下書きを作るまでの時間」です。数値や制度名の事実確認、個人情報や著作権物の取り扱い、断定表現のチェックといった最終確認は必ず人の目で行い、安心して公開できる台本に仕上げてください。

最初は工程が多く感じるかもしれませんが、チャンネル情報のメモやプロンプトのテンプレートを一度作ってしまえば、2本目以降は条件部分を書き換えるだけで同じ流れを繰り返せます。慣れてきたら、自分のチャンネルの口調や過去にウケた表現を加えてプロンプトをカスタマイズしていくと、ChatGPTが出す案もより自分らしいものに近づいていきます。まずは直近の1本で、本記事のプロンプトをそのまま試してみてください。
