## この記事でわかること

- AIに資格試験の勉強計画を立ててもらう基本の流れ
- 計画作成の精度を上げるために事前に用意すべき情報
- そのままコピペで使えるプロンプトテンプレート(4種類)
- 計画が崩れたときにAIで立て直す方法
- AIに学習計画を任せるときに気をつけたいリスク

資格試験の勉強でいちばん消耗するのは、実は「何をいつやるか」を決める作業そのものです。参考書を開く前に計画表とにらめっこして時間が溶けていく、休日に「今日は何章をやろうか」と考えているうちに午前中が終わってしまう、という経験がある方は多いのではないでしょうか。

ChatGPTやGeminiのような生成AIは、試験範囲・残り日数・1日に使える時間を伝えるだけで、たたき台となるスケジュールを数分で作ってくれます。もちろんAIが作る計画が最初から完璧というわけではありません。しかし、ゼロから自分で計画表を作る手間に比べれば、AIが出した叩き台を自分の生活に合わせて微調整するほうがはるかに時短になります。この記事では、資格試験向けの勉強計画をAIに作らせる具体的な手順と、実際に使えるプロンプト、そして使う上で知っておきたい注意点までをまとめました。社会人の資格取得はもちろん、学生の検定試験対策にも応用できる内容です。

## なぜAIに資格試験の勉強計画を任せると効率的なのか

勉強計画づくりは「情報整理」「優先順位付け」「スケジュール割り当て」という、AIが得意とする作業の組み合わせです。試験範囲のテキスト目次や過去問の出題傾向をAIに読み込ませれば、人力で何時間もかかる科目ごとの配分案を短時間でたたき台として提示してもらえます。

ただし、AIは万能の家庭教師ではありません。試験日程や出題範囲の最新情報を必ずしも正確に把握しているとは限らず、古い情報や誤った情報(いわゆるハルシネーション)を含む可能性があります。そのため、AIが作る計画は「叩き台」として扱い、試験範囲や日程などの事実情報は必ず公式サイトや公式テキストで確認する、という前提で使うことが大切です。

また、AIに相談するメリットは「計画を作ってもらえる」ことだけではありません。計画が崩れたときに気軽にやり直しを相談できる、曜日や生活パターンが変わったときにすぐ再調整してもらえる、といった「継続的に伴走してもらえる」点も大きな魅力です。紙の手帳やExcelで作った計画表は、一度崩れると作り直すのが面倒で放置されがちですが、AIとのチャットであれば数行のメッセージで再計画の相談ができます。なお、サービスやプランによっては1日に送れるメッセージ数などに制限がある場合があるので、その点は各サービスの案内を確認してください。

### ChatGPT・Gemini・Claudeなど、どのAIを使えばいいか

主要な生成AIチャットサービス(ChatGPT、Gemini、Claudeなど)は、いずれも本記事で紹介するようなテキストベースの計画作成プロンプトに対応しています。細かい機能や無料で使える範囲、対応している最新情報の範囲はサービスやプランによって異なり、またアップデートで頻繁に変わるため、本記事では特定のプランや料金を断定的に案内することは避けます。普段使い慣れているAIサービスがあれば、まずはそれで試してみて、出力の精度や使い勝手を比べてみるのがおすすめです。複数のAIに同じ条件で計画を作らせて、良いところを組み合わせるという使い方もできます。

## STEP1:AIに計画を作ってもらう前の準備

良い計画を作ってもらうコツは、AIに丸投げせず、必要な情報を先にこちらで整理しておくことです。以下の5項目をメモ帳やチャット欄に書き出しておきましょう。

1. **受験する資格試験名と試験日**(例:ITパスポート、2026年12月の試験)
2. **試験範囲・科目構成**(公式サイトのシラバスや目次をコピーしておく)
3. **現在の理解度**(初学者/一部既習/再受験など)
4. **平日・休日に確保できる勉強時間**(具体的な時間数)
5. **得意・苦手科目**(わかる範囲でOK)

この情報が揃っていると、AIは「残り日数×使える時間」から逆算した現実的な計画を作りやすくなります。情報が曖昧なまま依頼すると、実行不可能な詰め込み計画になりがちなので注意しましょう。

特に見落とされがちなのが「4. 平日・休日に確保できる勉強時間」です。希望的観測で「平日2時間」と伝えてしまうと、AIはその前提で計画を組んでしまい、結局実行できずに挫折につながります。残業がある日、家事や育児がある日なども考慮して、少し控えめな時間を申告するくらいがちょうど良いでしょう。余裕を持たせておけば、進みが良かった週に前倒しで進める、という使い方もできます。

また、試験範囲(2.)については、公式サイトのシラバスページや、使っているテキストの目次を丸ごとコピーしてAIに渡すのがおすすめです。見出しだけでも構いません。範囲の情報が具体的であるほど、AIは科目ごとの重要度やボリュームを踏まえた配分を提案しやすくなります。逆に「〇〇試験の勉強計画を作って」とだけ伝えると、AIが持っている(古いかもしれない)一般的な知識だけを頼りに計画を作ることになり、実際の出題範囲とズレるリスクが高まります。

## STEP2:AIに勉強計画を作らせる実践プロンプト集

準備が整ったら、実際にAIへ依頼してみましょう。以下はそのままコピーして、カッコ内を自分の情報に置き換えて使えるテンプレートです。

### テンプレート1:全体スケジュールの叩き台を作る

```
あなたは資格試験対策の学習コーチです。
以下の条件で、合格までの学習スケジュールの全体像を作ってください。

- 資格名:(例:簿記2級)
- 試験日:(例:2026年11月15日)
- 現在のレベル:(例:簿記3級は取得済み、2級の学習経験なし)
- 平日に使える時間:(例:1日1時間)
- 休日に使える時間:(例:1日3時間)
- 試験範囲・科目構成:(ここに公式シラバスや目次を貼り付け)
- 得意・苦手:(例:計算は得意、理論暗記が苦手)

出力してほしいもの:
1. 試験日までを「インプット期」「演習期」「直前期」の3段階に分けた月単位の計画
2. 各段階でやるべきことの概要
3. 苦手分野への配慮
4. スケジュールが遅れた場合の調整の考え方

まずは全体像だけを提示してください。週単位の詳細は次のステップで相談します。
```

このプロンプトのポイントは、いきなり日次の細かい計画を求めず、まず大枠(フェーズ分け)を作らせることです。全体像に納得してから細部に落とし込むほうが、後の手戻りが少なくなります。

### テンプレート2:週間スケジュールに落とし込む

```
先ほど作ってもらった全体計画のうち、
直近4週間分を週ごとの学習計画に分解してください。

条件:
- 平日(月〜金)は1日1時間、休日(土日)は1日3時間
- 各週に「今週の目標」を1行で明記
- 月〜金/土/日で曜日ごとにやる内容を分ける
- 週の最後に簡単な復習・振り返りの時間を入れる

表形式(曜日・学習内容・目安時間)で出力してください。
```

週単位まで落とし込むと、手帳やGoogleカレンダーに転記しやすくなります。表形式を指定しておくと、そのままスプレッドシートにコピーできて便利です。

### テンプレート3:過去問演習を計画に組み込む

```
これまでの学習計画に、過去問演習のタイミングを組み込みたいです。

条件:
- 試験日の(例:6週間前)から過去問演習を開始したい
- 過去問は(例:直近5年分、各回120分)
- 演習後は復習時間も確保したい
- 演習の結果次第で、苦手分野の復習期間を追加したい

演習開始から試験日までのスケジュール案と、
復習時間をどのくらい確保すべきかの目安を教えてください。
```

過去問演習は本番形式に慣れるだけでなく、自分の弱点を可視化する重要な工程です。AIに演習→復習のサイクルを組み込んでもらうことで、「解きっぱなし」を防ぐ計画になります。

### テンプレート4:計画が崩れたときのリスケジュール

```
学習計画より(例:1週間分)遅れています。
以下の状況をふまえて、試験日までの計画を立て直してください。

- 試験日まで残り:(例:5週間)
- 遅れている内容:(例:第3章の演習がまだ)
- 今後増やせる時間:(例:平日+30分だけなら可能)
- 優先したい内容:(例:配点の高い分野を優先したい)

無理のない範囲で、優先順位をつけた巻き返しプランを提案してください。
```

計画通りに進まないのはよくあることです。遅れを責めるのではなく、「残り時間でどう優先順位をつけ直すか」をAIに相談する使い方が、挫折を防ぐコツです。

## STEP3:作った計画を「使える形」に整える

AIが出力した計画は、チャット画面に表示されたままでは忘れてしまいがちです。次のような方法で、日常的に目に入る形に変換しておきましょう。

1. **表形式の出力をスプレッドシートに貼り付ける**(Googleスプレッドシートなら共有・リマインダー設定も可能)
2. **カレンダーアプリに転記する**(「今日のタスク」として毎日表示されるようにする)
3. **ToDoアプリに1日単位のタスクとして登録する**

AIに「このスケジュールをGoogleカレンダーに貼り付けやすいCSV形式で出力して」のように形式を指定すると、転記の手間をさらに減らせます。

さらに一歩進めるなら、朝イチや通勤時間にその日のタスクが自動で目に入るよう、リマインダーやカレンダーの通知機能と組み合わせるのがおすすめです。計画を「見に行く」のではなく「勝手に表示される」状態にしておくことで、忙しい日でも学習習慣が途切れにくくなります。

### 資格の種類によって計画の立て方を少し変える

一口に資格試験といっても、暗記中心の試験、計算・演習中心の試験、英語などの語学系試験では、AIに依頼する際の力点を変えるとより実用的な計画になります。

- **暗記量が多い試験**(法律・制度系など):「反復のタイミング」を重視した計画にしてもらいましょう。「1週目で覚えた内容を3週目にもう一度復習する期間を入れてください」のように、忘却を前提とした復習サイクルをリクエストするのがポイントです。
- **計算・演習が中心の試験**(簿記・統計系など):「毎日短時間でも手を動かす時間を確保する」計画にしてもらいましょう。知識のインプットよりも、演習量を優先した配分をお願いすると実践的です。
- **語学系の試験**(英語検定など):「聞く・読む・話す・書く」のうち、どの技能を伸ばしたいかを伝えると、技能ごとにバランス良く時間配分した計画を作ってもらいやすくなります。

依頼する際は、テンプレート1の「得意・苦手」欄に、こうした試験の性質や自分の弱点を書き添えておくと、AIがより実情に合った配分を提案してくれます。

## STEP4:進捗をAIと一緒に振り返る習慣をつくる

計画は作って終わりではなく、週に1回程度は進捗をAIに報告し、微調整してもらうのがおすすめです。

```
今週の学習報告です。

- 予定していた内容:(例:第4章の問題集1周)
- 実際にやった内容:(例:第4章を半分まで)
- 理解度の手応え:(例:計算問題は解けるが、用語の暗記が弱い)

この結果をふまえて、来週のスケジュールを調整してください。
```

この「報告→調整」のサイクルを回すことで、計画が一度きりの「作って満足」で終わらず、試験日まで伴走してくれるパートナーのような使い方ができます。週に1回、5分だけでもこの振り返りの時間を確保できると、計画と実態のズレが小さいうちに修正でき、試験直前になって「全然終わっていない」と慌てる事態を防ぎやすくなります。

振り返りのタイミングは、日曜の夜や、週明けの通勤時間など、自分の生活リズムの中に組み込みやすい時間を決めておくと習慣化しやすいです。AIとのやり取り自体を「今週の勉強ミーティング」のように位置づけてしまうと、継続のハードルがぐっと下がります。

## AIに勉強計画を任せるときの注意点

便利な一方で、いくつか気をつけておきたい点があります。

- **試験日程・出題範囲は必ず公式情報で確認する**:AIの回答には古い情報や誤りが含まれる可能性があります。特に制度変更があった資格は要注意です。
- **個人情報の入力は最小限にする**:氏名・勤務先・受験番号など、個人や所属が特定される情報は入力しないようにしましょう。学習計画の相談自体は、試験名・学習時間・得意不得意といった情報だけで十分成立します。
- **無料プランには利用回数や機能の制限がある場合がある**:各AIサービスの無料枠や有料プランの内容は変更されることがあるため、最新情報は各社の公式サイトで確認してください。
- **計画に固執しすぎない**:AIが作った計画はあくまでたたき台です。自分の体調やライフスタイルに合わせて、遠慮なく調整しましょう。
- **AIに過度に依存しない**:計画を作ってもらうこと自体が目的化してしまい、肝心の学習時間が削られては本末転倒です。計画作成に使う時間はできるだけ短く済ませ、浮いた時間を演習や復習に回すようにしましょう。
- **AIの回答を鵜呑みにしない**:特に問題の解説や論点の説明をAIに求める場合、誤った説明が含まれる可能性があります。学習内容そのものの正誤は、必ず公式テキストや信頼できる参考書で裏取りする習慣をつけてください。

これらの点を踏まえれば、AIは「計画を代わりに考えてくれる」だけでなく、「計画通りに進んでいるかを一緒に確認してくれる」心強いパートナーになってくれます。

## まとめ

AIを使った勉強計画作りは、「情報を整理して渡す」「全体像→週単位→日次の順に落とし込む」「定期的に報告して調整する」という3つの流れを意識すると、ぐっと実用的なものになります。今回紹介した4つのプロンプトテンプレートは、資格名や条件を置き換えるだけでどんな試験にも応用できます。

- まず全体スケジュールの叩き台を作ってもらう
- 直近4週間分を週単位に落とし込んでもらう
- 過去問演習のタイミングを組み込んでもらう
- 進捗がズレたら、遠慮せずリスケジュールを相談する

この4ステップを一通り試すだけでも、計画づくりにかかる時間はかなり短縮できるはずです。試験日程や出題範囲といった事実情報は必ず公式サイトで確認しながら、個人情報の入力は最小限にとどめつつ、AIを「計画づくりの相棒」として活用してみてください。まずは直近の試験について、全体スケジュールの叩き台を作るプロンプトから試してみましょう。計画づくりに使っていた時間を、そのぶん問題演習に回せるようになるはずです。
