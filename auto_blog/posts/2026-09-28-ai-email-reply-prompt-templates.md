## メール返信の下書きをAIに任せる前に押さえたい3つのポイント

毎日届く受信メールへの返信は、内容自体はシンプルでも「言い回しを考える」だけで地味に時間がかかる作業です。AIにメール返信を下書きさせると、この「文面を考える時間」を大きく減らせます。ただし「いきなり丸投げ」すると、当たり障りのない文章や、的外れな返信になりがちです。コツは、AIに渡す情報を整理してから依頼すること。テンプレートを使う前に、次の3つを意識してください。

**1. 相手からの元メールをそのまま貼り付ける**
要約せずに元の文面をコピペすると、AIが文脈や依頼内容を正確に拾えます。「何となく内容を伝える」だけだと、AIは前提を推測するしかなく、話がかみ合わない返信になりがちです。件名や署名部分は削ってもかまいませんが、本文はできるだけそのまま使いましょう。

**2. 「誰に・何を伝えたいか」を一言添える**
「取引先に納期遅延を謝罪したい」「上司に日程変更をお願いしたい」など、目的を先に書くと精度が上がります。相手との関係性(初対面か、長年の取引先か)や、社内向けか社外向けかによっても適切な言葉遣いは変わるため、この情報も一緒に伝えると仕上がりが安定します。

**3. 個人情報・社外秘の情報は伏せ字にする**
氏名や取引金額、契約番号などは「〇〇様」「金額は伏せています」のように置き換えてから入力するのが安全です。急いでいるときほどこの手順を省略しがちですが、一度入力してしまった情報は取り消せません。この点は記事後半で詳しく解説します。

## そのまま使えるプロンプトテンプレート5選

ここでは、実務でよく使う5つのシーン別に、コピペで使えるプロンプトを紹介します。角括弧「[ ]」の部分だけ書き換えて使ってください。プロンプトの中で「条件」を箇条書きにしているのは、AIに何を守ってほしいかを明確にするためです。条件を書かずに「返信を作って」とだけ頼むと、文字数もトーンもバラバラな下書きが出てきやすいので、面倒でも条件欄は残したまま使うことをおすすめします。

### 1. お詫びメールの返信

納期遅延やミスへの謝罪など、丁寧さと誠実さが求められる場面向けです。

```
あなたはビジネスメールの文章作成アシスタントです。
以下の受信メールに対する返信メールの下書きを作成してください。

【状況】
[例:納品が3日遅れることになった。原因は資材の調達遅延]

【受信メール】
[相手からのメール本文をそのまま貼り付け]

【条件】
- 冒頭でお詫びの言葉を述べる
- 遅延の理由を簡潔に説明する（言い訳っぽくならないように）
- 今後の対応策と新しい納期を明記する
- 文字数は300〜400字程度
- 敬語は「です・ます」調で、丁寧だが堅すぎない
```

### 2. 日程調整メールの返信

社内外を問わず頻度が高い「日程調整」のやり取り向けです。

```
以下の受信メールに、日程調整の返信メールを作成してください。

【受信メール】
[相手からのメール本文をそのまま貼り付け]

【自分の候補日時】
[例:9/30(火)14時〜、10/1(水)10時〜、10/2(木)終日可]

【条件】
- 候補日時を箇条書きで提示する
- どの日程でも相手に合わせられる旨を一言添える
- オンライン/対面どちらでも対応可能なことを伝える
- 文字数は200字程度で簡潔に
```

> **ワンポイント**：AIは実際のカレンダーの空き状況を見ているわけではありません。提示する候補日時は必ず自分で確認したうえで入力してください。

### 3. 依頼を断るメールの返信

角を立てずに断る、という難易度の高い返信をAIに任せると特に時短効果が高いパターンです。

```
以下の依頼メールに対して、丁重にお断りする返信メールを作成してください。

【受信メール】
[相手からのメール本文をそのまま貼り付け]

【断る理由】
[例:現在のリソースでは対応が難しいため]

【条件】
- 依頼への感謝をまず伝える
- 断る理由は簡潔に、詳しく言い訳しすぎない
- 可能であれば代替案を1つ提示する（なければ省略可）
- 関係性を損なわない、次にもつながる文面にする
```

> **ワンポイント**：柔らかい表現を優先しすぎると、相手に「断られた」ことが伝わらない場合があります。下書きを読み返し、結論（お断りする旨）が明確になっているか確認してから送りましょう。

### 4. 問い合わせ対応メールの返信

顧客・取引先からの質問に、正確かつ読みやすく回答するためのテンプレートです。

```
以下はお客様からの問い合わせメールです。この内容に対する回答メールの下書きを作成してください。

【問い合わせメール】
[相手からのメール本文をそのまま貼り付け]

【回答に使う情報】
[例:料金は月額○○円、契約期間は最低1年、解約は30日前までに連絡が必要]

【条件】
- 質問項目ごとに分かりやすく回答する（箇条書き可）
- 分からない・確認が必要な点があれば正直にその旨を書く
- 最後に「他にご不明点があればお気軽にお問い合わせください」で締める
```

> **ワンポイント**：質問が3つ以上ある場合は、番号付きリストで回答するよう条件に加えると、相手にとっても対応状況が分かりやすくなります。

### 5. 英文メールへの返信（日本語→英語）

海外の取引先とのやり取りで、日本語で考えた内容を英文に変換したいときに使います。

```
以下の英文メールに対する返信を、ビジネス英語で作成してください。
まず日本語で返信内容の要点を伝えるので、それを自然なビジネス英語に翻訳・整形してください。

【受信メール（英文）】
[相手からのメール本文をそのまま貼り付け]

【日本語での返信内容の要点】
[例:見積もりを確認した。数量を100個から150個に変更したい。納期は変わらないか確認したい]

【条件】
- フォーマルすぎず、かといってカジュアルすぎない、標準的なビジネストーン
- 冒頭に相手のメールへの一言（感謝や確認の言葉）を入れる
- 質問は明確に、箇条書きにしてよい
```

### テンプレートを使うとどんな下書きが出てくるか

イメージが湧きやすいように、「1. お詫びメールの返信」テンプレートを使ったときの出力例を簡単に紹介します。

```
件名：Re: ご注文商品の納期について

〇〇様

いつもお世話になっております。
このたびは、ご注文いただいた商品の納品が3日ほど遅れる見込みとなり、
大変ご迷惑をおかけしますことをお詫び申し上げます。

原因は資材の調達に時間を要したことによるものです。
現在は代替ルートでの手配を進めており、
新しい納品予定日は10月3日（金）を見込んでおります。

ご不便をおかけし申し訳ございませんが、
何卒ご理解のほどよろしくお願いいたします。
```

このように、条件を細かく指定するほど「そのまま使える」下書きに近づきます。もちろん実際に送る前には、日付や固有名詞に誤りがないか必ず自分の目で確認してください。特にAIは日付や金額などの数字を誤って生成することがあるため、本文に登場する数字は必ず元のメールや自分の記憶と照合しましょう。

なお、条件欄に「件名も一緒に作成してください」と一言加えれば、本文と統一感のある件名も同時に生成してくれます。返信メールでは元の件名に「Re:」を付けるだけで十分な場合も多いですが、内容が大きく変わる場合は件名も見直すと親切です。

## トーンや長さを後から微調整するテクニック

一度出てきた下書きが「ちょっと硬い」「もう少し短くしたい」というときは、最初からやり直さず、追加の指示で調整するのが時短のコツです。

- 「もう少しカジュアルなトーンにしてください」
- 「文字数を半分程度に短くしてください」
- 「謝罪の表現をもう少し強めてください」
- 「箇条書きではなく、文章としてつなげてください」
- 「一文をもっと短く、テンポよく読める文章にしてください」
- 「この一文だけもう少し丁寧な言い回しにしてください」

このように一言追加するだけで、AIは直前の下書きを踏まえて修正してくれます。たとえば最初の下書きが少し事務的すぎると感じたら、「もう少し温かみのある言葉遣いにしてください」と伝えるだけで、文面全体のトーンを保ったまま該当箇所だけ調整してくれます。何度かやり取りしながら仕上げていく感覚で使うと、最初から完璧なプロンプトを書く必要がなくなります。慣れないうちは、1回の指示に詰め込みすぎず「まずトーン」「次に長さ」のように1つずつ調整していくと、意図した仕上がりに近づけやすくなります。

## ChatGPT・Gmail(Gemini)・Copilotでの使い方の違い

同じテンプレートでも、ツールによって下書きの呼び出し方や強みが異なります。

**ChatGPT（ブラウザ・アプリ）**
上記のテンプレートをそのままチャットに貼り付けて使う、最もシンプルな方法です。無料プランでも基本的な下書き作成は可能ですが、プランによって使えるモデルや利用回数の上限が異なるため、契約前に公式サイトで最新のプラン内容を確認しておくと安心です。また、よく使う文体の好み（例：「一人称は『私』」「語尾は柔らかめ」など）をあらかじめ伝えておくチャットを1つ作っておくと、毎回同じ条件を書かずに済み、さらに時短になります。

**Gmail の Gemini（文章作成サポート）**
Gmailの作成画面から直接下書きを生成できるのが特徴です。Geminiで、関連性が高く、パーソナライズされた、役に立つ下書きが生成されるようにするには、プロンプトをできるだけ具体的かつ詳細に記述することが推奨されています。また、「文書作成サポート」を使用すると、自分の他のメールやGoogleドライブにあるファイルから関連情報を自動的に取得し、明示的な指示を与えなくてもトーンやスタイルに合った返信を作成できる仕組みになっています。過去のメールとの文体の一貫性を保ちたい人には向いています。

**Microsoft Copilot（Outlook）**
法人向けのCopilotには段階があり、追加費用なしで使えるMicrosoft 365 Copilot Chatと、社内データにより深く踏み込んで支援する有料のMicrosoft 365 Copilotの2種類がある点が特徴です。会社のメールデータや過去のやり取りを踏まえた返信を作りたい場合は、契約プランによって使える機能が変わるため、社内のIT担当者にどのプランが導入されているか確認しておきましょう。

いずれのツールも、料金プランやモデルの提供状況は数か月単位で更新されています。本記事のテンプレート自体はどのツールでも使い回せますが、契約前には必ず各社の公式ページで最新の料金・機能を確認してください。

どれを選べばよいか迷ったときの目安は次のとおりです。

- とりあえず試したい・個人利用が中心 → ChatGPT
- Gmailでのやり取りが多く、過去メールとの文体統一を重視したい → Gmail の Gemini
- Outlookや会社支給のMicrosoft 365を使っており、社内データも活用したい → Microsoft Copilot

会社でどのツールが導入・許可されているかは組織によって異なるため、迷ったら情報システム部門に確認するのが確実です。

## 個人情報・機密情報を入力するときの注意点

メール下書きの精度を上げようとして、元のメール文面をそのまま貼り付けたくなりますが、その際は次の点に注意してください。

- **氏名・住所・電話番号などの個人情報**は、可能であれば「〇〇様」「××市在住」のように仮名・伏せ字に置き換えてから入力する
- **契約金額・取引先名・社内の未公開情報**は、社内規定でAIツールへの入力が許可されているか事前に確認する
- **会社が契約しているAIツールの利用規約**を確認し、入力データが学習に使われる設定になっていないかチェックする
- 特に無料プランや個人アカウントでは、入力内容の取り扱いが有料の法人向けプランと異なる場合があるため、業務利用の際は会社支給のアカウント・プランを使う
- 未公開の新商品名や、社外に出ていない人事情報なども、下書き作成の題材としてそのまま貼り付けない
- CCやメール本文中に第三者の名前・連絡先が含まれている場合は、その部分も削除・伏せ字にしてから貼り付ける

たとえば「取引先の田中様から300万円の見積もり依頼が来た」という文面をそのまま貼り付けるのではなく、「取引先の担当者様から見積もり依頼が来た（金額は伏せる）」のように抽象化してから入力すれば、下書きの精度を大きく落とさずにリスクを減らせます。「時短のためにコピペしたら、実は社外秘の情報を外部サービスに送っていた」という事態は避けたいところです。少し手間でも、貼り付ける前に一度内容を見直す習慣をつけておくと安心です。

## まとめ

メール返信の下書きは、AIが最も得意とする作業のひとつです。今回紹介した5つのテンプレート――お詫び・日程調整・お断り・問い合わせ対応・英文返信――を状況に合わせて使い分ければ、白紙から文面を考える時間を大きく減らせます。

ポイントを振り返ると次の3つです。

1. 元メールはそのまま貼り付け、目的を一言添える
2. 出てきた下書きは「トーン」「長さ」を少しずつ追加指示で調整する
3. 個人情報・社外秘の情報は入力前に伏せ字にする

はじめから完璧な下書きを狙う必要はありません。まずは今日届いたメールの1通に、紹介したテンプレートのどれかをそのまま試してみてください。出てきた文面をたたき台にして、自分の言葉で少し手を加えるだけでも、ゼロから書くよりずっと早く返信を仕上げられるはずです。そして何より、個人情報や社外秘の情報を入力する前には、一呼吸置いて内容を確認する習慣を忘れずに。安全に使いこなして、メール対応の時間をぐっと短縮していきましょう。
